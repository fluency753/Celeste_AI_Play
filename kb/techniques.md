# 移动技巧（Tech）

本文件收录"怎样利用规则移动得更快/更远/更高"的技巧：Strawberry Jam（草莓酱）训练场 Beginner→Grandmaster 五个 gym 教授的全部技巧，加上 Celeste Community Wiki（celeste.ink）技巧页列出的全部原版技巧（只存在于 mod 的机制除外），去重后每个技巧一个条目，别名并列。机制库（SJ Library：碰撞容错、摩擦、冻结帧、计时等"规则本身"）以及后续章节实体的交互规则放在 `mechanics.md`。

本文件只写技巧的定义、条件、帧窗口和数值，不写任何房间布局、路线、解法或收集品位置。原始常量与更新顺序以 `player_physics.md`、`input.md`、`entities.md` 为准，本文只引用其章节，不重复常量表。

## 0. 约定

### 0.1 帧记号（与 `player_physics.md` §8.2 一致）

- **F0**：冲刺被受理的帧（该帧速度被清零，不移动）；**F1–F3**：冻结帧；**F4**：第一个正常帧，读取冲刺方向；**F4–F13**：以冲刺速度移动；**F14**：最后一次 DashUpdate，然后冲刺结束、设定结束速度；**F15**：第一帧 StNormal，冲刺冷却恰好到期；**F15–F20**：冲刺状态已结束，但仍处于"冲刺攻击"（DashAttacking）中。
- **J**：起跳类函数执行的帧。**L**：落地碰撞发生的帧（该帧的垂直移动撞到地面，触发落地回调）。**E**：梦境冲刺结束的帧（梦境块出口）。
- 除非特别说明，"第 k 帧之后"按**正常帧**计；冻结帧不推进任何计时器（土狼、可变跳、冷却……），但**按键缓冲照常递减**（`input.md` §2）。

### 0.2 输入例写法（harness）

- 按 `game_data.md` §3：`"帧数,键,键…"`；**段与段之间不自动松键**；J、X、Z 每次"按下"之前必须至少有 1 帧松开；缓冲 5 帧且只在按住期间有效（`input.md` §2）。
- 冲刺方向只看 **F4** 那一帧的方向键（`input.md` §5.3、§8）；F0 只决定"是否下蹲冲刺"（F0 按住 D 或使用 Z）。
- 输入例默认：**朝右**（向左时镜像 L/R），冲刺可用（次数 ≥ 1 且冷却已过），序列开始前所有键都已松开。
- `<n>` 表示取决于地形的帧数，条目里会给出如何确定。
- harness 的 `act` 帧数**包含冻结帧**；章节计时（IGT）**不包含冻结帧**（见 0.5）。

## 2. 地面与跳跃类

### 2.1 跳跃加速（Jump boost，"+40"）

- **作用**：所有"普通起跳"在起跳帧给水平速度加 `40 × moveX`。普通起跳包括地面跳、土狼跳、爬墙跳（含越过墙角的爬墙跳）、梦境跳。按反方向则减 40，可用来刹车。
- **前置**：起跳帧的 moveX ≠ 0（被强制水平输入期间取强制值）。super、hyper、蹬墙跳、墙弹直接**赋值**水平速度，不加 40。
- **输入**：`["1,R,J", "11,R,J"]`。
- **结果**：90 → 130。是兔子跳、抓角加速、梦境双跳拿速度的来源。
- **本轮章节**：✓ / ✓ / ✓
- **来源 / 核实**：SJ Library "Jump Boosts"；celeste.ink；【代码已核实】（普通起跳函数在设置 −105 之前先加 40·moveX）。

### 2.2 兔子跳（Bunnyhop，bhop，连续兔子跳 chained bhop）

- **作用**：落地后第一个"在地面"的帧立刻起跳，少吃地面摩擦，并且每跳拿一次 +40。
- **前置**：在地面；超过 90 时一直按前进方向（空中超速减速 4.333/帧，地面 6.667/帧；不按方向时减速 10.833 / 16.667 每帧）。
- **输入**：`["1,R,J", "<a>,R", "5,R,J"]`。第一跳只按 1 帧，空中松开；在落地帧 L 的下一帧之前 ≤4 帧开始按住 J（缓冲），J 就会在 L+1 执行。
- **帧窗口**：L 帧的移动里撞到地面；L+1 帧开始时 onGround 为真，同一帧里先算地面水平摩擦，再执行起跳（+40）。
- **结果**【由规则推算】：从 90 起，每跳只按 1 帧（滞空 14 帧），平均水平速度约 104 px/s，比跑步快约 15%；每跳按满时约 96 px/s。速度高于约 130 时，每跳净变化为 `40 − 6.67 − 4.33 × 滞空帧数`：滞空 ≥ 8 帧就净减速。所以兔子跳只能**减缓**超速衰减，不能无限加速。
- **本轮章节**：✓ / ✓ / ✓（序章不能冲刺，这是最快的平地移动方式）
- **来源 / 核实**：celeste.ink、BWIKI、NamuWiki；【代码已核实】（StNormal 里水平速度更新先于跳跃判定）；平均速度【由规则推算】。

### 2.3 跳跃高度控制（Jump control）与浮空跳（float jump）

- **作用**：用按住跳的时长控制高度；利用顶点附近的半重力做"低而远"的跳。
- **规则**：可变跳期间（起跳帧及之后 11 帧，共 12 帧）只要按住跳，vy 不大于起跳速度；**某帧没按住就永久取消本次可变跳**。|vy| < 40 时，按住跳（或 AutoJump）重力减半：每帧 +7.5，否则 +15（`player_physics.md` §5.2 第 7–8 步）。冲刺结束后 AutoJump 自动为真，一直保持到落地。
- **浮空跳输入**：`["1,R,J", "1,R", "20,R,J"]`。起跳后松开 1 帧（取消可变跳），再按住（进入半重力区时减慢下落）。
- **结果**【由规则推算】：按满 27 px / 39 帧；只按 1 帧 7 px / 15 帧；浮空跳 7.5 px / 20 帧。浮空跳与只按 1 帧高度相同，但多飞 5 帧，水平多约 7 px（在 130 时）。hyper、super、墙弹同样适用，例如"受控 hyper"：hyper 后很快松开跳。
- **本轮章节**：✓ / ✓ / ✓
- **来源 / 核实**：SJ Library "Jump Control"；NamuWiki（slowfall）；【代码已核实】。

### 2.4 土狼时间（Coyote time / coyote jump，狼跳）

- **作用**：离开地面后仍可起跳，也可以做 super/hyper（冲刺状态里判断的是同一个计时器）。
- **规则**：每个 onGround 帧把计时设为 0.1 s，离地后每个正常帧减一次 → 离地后 **5 帧**内可起跳。冻结帧不减。起跳后清零（只能跳一次）。土狼期间站地补冲刺**不会**发生（补冲刺要求 onGround）。
- **其他来源**：水平或斜向穿出梦境块（0.1 s）；后续章节的岩浆块（碎裂把人甩开时）、消失中的碎裂平台。
- **土狼 super/hyper**：离地后的第 g 帧（第一个空中帧）到 g+3 帧之间受理冲刺，并让跳键在 F4 处于"按下"，F4 就会执行 super（下蹲时为 hyper），见 7.1。更晚的冲刺需要冲刺方向是水平的，并且在土狼计时 > 0 时按跳。
- **输入**：走下平台后 `["<k≤4>,R", "1,R,J", "11,R,J"]`。
- **本轮章节**：✓ / ✓ / ✓（super/hyper 序章 △ 教学后）
- **来源 / 核实**：SJ Library "Coyote Time"；celeste.ink；【代码已核实】。

### 2.5 预输入（Input buffering）

- **作用**：提前最多 4 帧按下并按住，动作在第一个可执行帧自动发生。
- **规则**：跳、冲刺、蹲冲、交互的缓冲都是 0.08 s（按下帧 + 4 帧 = 5 帧），松开立即清空；冻结帧也消耗缓冲；抓没有缓冲（`input.md` §2）。
- **用法**：
  - 缓冲起跳：兔子跳（2.2）。
  - 缓冲蹬墙跳：在与墙的间隙 ≤ 2 px 的第一帧自动蹬墙（4.1）。
  - 缓冲冲刺：冷却中、落地前（补冲刺）、吃水晶时。吃到水晶会冻结 3 帧，冻结会消耗缓冲，所以冲刺键最好在吃到水晶的那一帧或之后（冻结帧里）按下并按住（冻结起始帧为推断，未核实）。
  - 缓冲冲刺接弹簧（buffered spring cancel）：地面弹簧会补满冲刺并把状态设为 Normal；冷却允许时，下一帧就能冲刺。
  - 缓冲爬墙跳：上升中（vy < 0）不会抓墙，所以按住抓 + 缓冲跳会在 ≤ 2 px 处直接爬墙跳，不进入攀爬状态。这样不会"骑"在墙上，不触发交通块、坠落块这类骑乘机关（见 `mechanics.md` Collision Leniency）。
- **本轮章节**：✓ / ✓ / ✓
- **来源 / 核实**：SJ Library "Input Buffering"；NamuWiki；【代码已核实】（缓冲规则见 `input.md`）。

### 2.6 快速下落（Fastfall，速降）

- **作用**：下落速度已达 160 时按住下，上限每帧 +5，16 帧后到 240。
- **输入**：`["<n>,D"]`（空中）。注意：按住 D 会让贴墙下滑失效、让下一次冲刺变成下蹲冲刺（F0 按住 D）、地面上会下蹲。
- **结果**【由规则推算】：从 vy = 0 落 100 px：43 帧 → 35 帧；落 200 px：80 → 60；落 400 px：155 → 110。
- **本轮章节**：✓ / ✓ / ✓
- **来源 / 核实**：SJ Library "Falling Speed"；【代码已核实】（`player_physics.md` §5.5）。

### 2.7 下蹲、蹲跳、蹲姿爬墙跳（Crouch / Crouch jump / Crouch climb）

- **作用**：碰撞箱 8×6、受击箱 8×4（`README.md` §4），可以通过高 6–10 px 的缝，在危险物之间的窄缝里存活。
- **规则**【代码已核实】：
  - 只有在地面、按住下、vy ≥ 0 时开始下蹲；地面下蹲时不能加速，水平速度以 8.333/帧趋向 0。
  - 普通起跳**不**取消下蹲。空中只要还在上升、仍在土狼时间内、或头顶放不下站立碰撞箱，就一直保持下蹲；开始下落（vy > 0）且土狼时间已过、能起身时自动起身。
  - 下蹲时不能抓墙，但**可以爬墙跳**，而且爬墙跳不取消下蹲；蹬墙跳、super、墙弹会取消下蹲。
  - 地面冲刺撞到前方只有 6 px 高的缝时，会自动进入下蹲继续冲刺，不损失速度。
  - 注意：爬墙跳、蹬墙跳、super/hyper 都要求起跳那一刻"能起身"（当前位置放得下 8×11 的站立碰撞箱）。所以在 1 格（8 px）高的通道**里面**不能起跳。SJ 的"蹲跳后连续爬墙跳穿过 1 格高的缝"是：每次在缝外能起身的位置起跳，靠 8×6 的下蹲碰撞箱上升穿过缝【代码已核实】。
- **输入**：蹲跳 `["1,D,J", "11,J"]`（同一帧先下蹲、后起跳，两者在 StNormal 里按此顺序判定）。
- **本轮章节**：✓ / ✓ / ✓
- **来源 / 核实**：SJ Advanced Gym "Crouch Jump"、Library "Crouching"；celeste.ink；【代码已核实】。

### 2.8 摩擦与速度保持（Friction）

- **规则**（每帧，速度高于 90 时；`player_physics.md` §5.3）：

| 情况 | 每帧减速 |
| --- | --- |
| 空中，按前进方向 | 4.333 |
| 空中，不按或按反方向 | 10.833 |
| 地面，按前进方向 | 6.667 |
| 地面，下蹲 | 8.333 |
| 地面，不按或按反方向 | 16.667 |

- **实用结论**：高速时在空中一直按住前进方向；尽量少接触地面（兔子跳）；地面滑行时不要按下。
- **本轮章节**：✓ / ✓ / ✓
- **来源 / 核实**：SJ Library "Friction"；【代码已核实】。

### 2.9 失败 hyper / 失败 wavedash（Failed hyper / failed wavedash）

- **作用**：故意让地面斜下冲刺在地面上结束，结束速度 160；之后正常起跳，得到"普通起跳高度、速度约 193"的跳，同时冲刺已经补满。
- **前置**：斜下（或任何会在地面转成水平的）冲刺在 F14 时仍在地面上；不在 F14 之前按跳。
- **输入**：`["1,R,X", "3,R,D", "1,R,D", "10,R", "1,R,J", "11,R,J"]`。F4 斜下，F5–F14 只按 R（F14 结束时速度变为 160），F15 起跳。起跳帧不要按 D，否则保持下蹲，摩擦变成 8.333。
- **结果**【由规则推算】：F15 先吃一帧地面摩擦 160 → 153.3，再 +40 → 193.3；按满跳水平约 80 px（跑跳 62 px，super 116 px）。冲刺在 F10 之后已站地补满。
- **本轮章节**：△（教学后）/ ✓ / ✓
- **来源 / 核实**：SJ Library "Dash Speed"；NamuWiki；【代码已核实】。

## 3. 冲刺类

### 3.1 冲刺基础：方向、速度保留、冲刺间隔（Dash speed / Dash spacing）

- **规则**（`player_physics.md` §8）【代码已核实】：
  - 方向取 F4 的 8 向输入；速度 240（斜向每轴 169.71）。
  - 若冲刺前的水平速度与冲刺方向同号且更快，保留更快的水平速度。竖直方向不保留。
  - 结束（F14）：正上、水平、斜上 → `方向 × 160`，向上分量再 ×0.75（正上结束 −120）；正下、斜下 → 保持冲刺中的速度。
  - 冷却：下一次冲刺最早在 F15。
  - 冲刺开始前会先加上平台速度（LiftBoost），见 6.1。

### 3.2 Super（superdash，大跳，super 冲）与 extended super（延长 super）

- **作用**：把水平冲刺转成速度 260、普通高度的跳。
- **前置**【代码已核实】：处于冲刺状态，冲刺方向"水平"（|DashDir.Y| < 0.1）——包括正左/右、在地面上被转成水平的斜下冲刺、以及 F4 时方向尚未设定（见 7.1）；本帧跳键"按下"；土狼计时 > 0（在地面或离地 5 帧内）；能起身；**不在下蹲**（下蹲则变成 hyper）。
- **帧窗口**：F4–F14。**Extended**：在 F10–F14 起跳且该帧在地面上 → 本帧先补满冲刺（补冲刺检查在冲刺更新之前），再 super，于是离地时已有冲刺。

### 3.3 Hyper（hyperdash，超冲）与 extended hyper

- **作用**：下蹲状态下的 super：更快更低（325，−52.5）。
- **前置**：同 super，并且起跳帧处于**下蹲**。下蹲来源【代码已核实】：F0 用 Z 键或按住 D；地面斜下冲刺在 F4 转成水平时自动下蹲；空中斜下冲刺落地转换（wavedash，3.4）；地面冲刺钻进 6 px 高的缝时自动下蹲。**冲刺方向不重要，只看是否下蹲**：水平冲刺只要处于下蹲，起跳也是 hyper。
- **结果**：vx = 325·Facing + 1.25·Lx，vy = −52.5 + 0.5·Ly，可变跳 0.2 s。按满跳 12 px 高 / 131 px 远 / 30 帧；只按 1 帧 2 px 高 / 41 px 远 / 8 帧【由规则推算】。
- **输入**：

  - Extended hyper（推荐写法）：`["1,R,Z", "3,R", "6,R", "1,R,J", "11,R,J"]`。F4 方向为右，得到在地面上的下蹲水平冲刺，速度 240，F10 hyper 并补满冲刺。
  - 经典写法：`["1,R,X", "3,R,D", "1,R,D", "5,R", "1,R,J", "11,R,J"]`。斜下冲刺在 F4 转成水平，速度 169.71 × 1.2 = 203.6。

### 3.4 Wavedash（凌波微步，凌波）

- **作用**：从空中斜下冲刺，在冲刺途中落地再起跳 = 空中开始的 extended hyper。适合很小的平台，也能补回冲刺。
- **前置**：空中斜下冲刺；冲刺开始时脚底离落点表面的高度 h ≤ 约 28 px（F4–F13 共下降 28.3 px），保证在冲刺状态内落地。

### 3.10 Ultra（ultradash，究极冲刺，u）

- **作用**：高速斜下冲刺在空中结束（斜下冲刺结束不重置速度），之后落地时水平速度 ×1.2。
- **规则**【代码已核实】：任何状态下，只要落地碰撞时 vy > 0、且"上一次冲刺方向"仍是斜下（DashDir.X ≠ 0 且 DashDir.Y > 0），就执行：vx ×1.2，vy = 0，进入下蹲，冲刺方向改为水平（标记用掉）。冲刺方向只在下一次冲刺开始时清零，所以中间经过别的状态也保留（见 3.13）。
  - 如果落地发生在冲刺状态内（F13 之前的移动），转换照样发生，但 F14 冲刺结束时方向已是水平 → 速度被重置为 160。此时只能在 F14 前起跳得到 hyper（325），这就是 wavedash。
  - 若落地帧 L 的移动恰好停在地面上而没有"撞"到（本帧位移刚好等于离地间隙），L+1 帧 onGround 已为真但 ×1.2 还没发生。此时若在 L+1 起跳（包括缓冲的跳），就永远拿不到这次 ×1.2（标记会留到下一次落地）。所以落地后至少"滑"1 帧再跳，或者看轨迹确认 vx 已乘 1.2 再跳。
- **前置**：冲刺开始时脚底离落点 > 约 28 px（F4–F13 下降 28.3 px）；冲刺前有高水平速度。
- **最佳接法**：extended hyper 在 **F14** 起跳；F15 立即斜下冲刺。F15 状态更新先受理冲刺，不吃空中摩擦，所以保留的就是 325。
- **输入**：`["1,R,Z", "3,R", "10,R", "1,R,J", "1,R,X", "3,R,D", "1,R,D", "<m>,R", "1,R", "1,R,J", "11,R,J"]`。F14 hyper；F15 冲刺（F0 不按 D）；F4' 斜下；`<m>` 帧下落到 L；滑 1 帧；起跳。
- **结果**：落地 vx = (325 − 4.333 × 冲刺结束到落地的空中帧数) × 1.2 ≈ 390；起跳 −6.667 + 40 → ≈ 423。比 hyper 快约 20–30%。普通空中斜下冲刺（无前置速度）：169.7 → 203.6，起跳后 ≈ 237。

- **来源 / 核实**：SJ Expert Gym "Ultra"、Library "Ultra Mechanics"；celeste.ink；BWIKI；【代码已核实】。

### 3.11 连续 Ultra（Chained ultras，连 u）

### 3.12 平地 Ultra（Grounded ultra，gultra，平地 u）与连续平地 ultra

- **作用**：在地面上（或冲刺开始时被吸到地面）斜下冲刺，F4 转水平时保留的高水平速度 ×1.2。
- **规则**【代码已核实】：F4 时在地面上、斜下 → vx ×1.2、下蹲、方向改为水平。之后若冲刺正常结束（F14）→ 速度被重置为 160；在冲刺中起跳 → hyper（固定 325，加成丢失）。**必须用别的方式取消冲刺才能保住 390**：本三章可用的取消方式是爬墙跳（抓角加速，+40 → 430）、向下换房（保留 vx），见 3.14。
- **冲刺开始时的贴地**：hyper 起跳后 1–2 帧内冲刺，F0 时脚离地 ≤ 2 px，冲刺贴地会把人拉回地面，所以 F4 在地面上【代码已核实】。
- **ultra → gultra**：ultra 落地（已 ×1.2）后滑至少 1 帧，再在地面上斜下冲刺 → 再 ×1.2。注意：若在"已贴地但还没撞地"的那一帧冲刺，冲刺开始会清零冲刺方向，第一次 ×1.2 就丢了。

### 3.13 延迟 Ultra（Delayed ultra，du）

- **作用**：斜下冲刺在落地**前**被取消，冲刺方向标记仍是斜下，下一次落地（vy > 0）时照样 ×1.2。
- **前置**：取消方式不改变冲刺方向，并且尽量保住水平速度。最好的是爬墙跳（抓角加速：保留 vx + 40）；蹬墙跳（vx = 130，损失大）。后续章节还有拾取物品、弹跳实体。

## 4. 墙与攀爬类

### 4.1 蹬墙跳、爬墙跳、翻墙、贴墙下滑的距离与容错（Collision leniency）

- **规则**（`player_physics.md` §5.11、§9）【代码已核实】：

| 动作 | 与墙的最大间隙 | 备注 |
| --- | --- | --- |
| 抓墙（进入攀爬） | 1 px | 还要求 vy ≥ 0、不疲劳、不下蹲、不背向移动；头顶 1–2 px 可抓墙辅助 |
| 蹬墙跳 / 爬墙跳 | 2 px | 爬墙跳不进入攀爬状态，不"骑"墙，不触发骑乘机关 |
| 墙弹（正上冲刺攻击中） | 4 px | 墙上 5 px 处有朝向自己的尖刺时退化为 2 px |
| 贴墙下滑 | 0 px（紧贴） | 按住墙方向或无方向 + 抓；按住下时不滑 |

- 蹬墙跳**只需碰撞箱与墙在竖直方向重叠 ≥ 1 px**，因此能从墙的最顶角蹬出（4.7）。
- 地面起跳优先于一切墙跳：土狼计时 > 0 时按跳是普通起跳。
- 贴墙下滑：下落上限在 72 帧内从 20 线性升到 160（每帧约 +1.94）。
- **输入**：缓冲蹬墙跳（向右墙）`["5,R,J", "10,R,J"]`。在间隙 ≤ 2 px 的第一帧执行；起跳时有水平输入，所以之后 10 帧水平输入被强制为离墙方向。

- **来源 / 核实**：SJ Library "Collision Leniency"；NamuWiki；【代码已核实】。

### 4.2 墙弹（Wallbounce，WB，蹭墙跳，弹墙跳）

- **作用**：正上冲刺中贴墙起跳，变成速度 (170, −160)、可变跳 0.25 s 的超级蹬墙跳。
- **前置**【代码已核实】：冲刺方向为正上（上一次冲刺）；处于冲刺攻击中；墙在 4 px 间隙内（有朝向自己的尖刺时 2 px）；能起身；跳键"按下"。
  - 冲刺状态内：**F5–F14**。F4 不行：F4 时冲刺方向尚未设定，那一帧的跳会变成普通蹬墙跳；若在地面上，则变成 super。
  - 冲刺结束后：F15–F20（冲刺攻击仍在），要求土狼计时 ≤ 0（站在地面上会变成普通起跳），且没有"朝墙 + 按住抓 + 有体力"（否则变成爬墙跳）。
- **结果**：vx = 170·dir + Lx，vy = −160 + Ly，可变跳 15 帧（含起跳帧）；不强制水平输入，起跳后可以自由控制；**不补冲刺**；取消下蹲。
- **高度**【由规则推算】：从起跳点算按满跳 +54 px（普通蹬墙跳 +27）。从冲刺起点算：F5 墙弹 ≈ 58 px，F14 墙弹 ≈ 94 px，F20 墙弹 ≈ 102 px。越晚墙弹越高（SJ："初速相同，但起点更高"）。
- **输入**（右侧有墙）：`["1,U,X", "3,U", "1,U", "1,U,J", "14,J"]`，F5 墙弹；晚墙弹：`["1,U,X", "3,U", "10,U", "1,J", "14,J"]`，F14 墙弹。
- **变体**：泡泡墙弹（后续章节）、换房墙弹（6.5）、梦境块后墙弹（6.3）、冲刺砖/移动块墙弹（墙在动时 + 平台速度）。
- **本轮章节**：△（教学后）/ ✓ / ✓
- **来源 / 核实**：SJ Intermediate Gym "Wallbounce"；celeste.ink；BWIKI；NamuWiki（"第 1–15 帧成功、16–21 帧延迟成功"，从 1 数，与代码一致）；【代码已核实】。

### 4.3 墙弹引申（Wallbounce leniency；带刺墙弹 Spiked wallbounce；墙弹取消 Wallbounce cancel）

- **冲刺后墙弹**：见 4.2，F15–F20 共 **6 帧**【代码已核实】。SJ Grandmaster Gym 文本写"冲刺结束后 5 帧"【社区说法与代码不符（差 1 帧，可能是数帧方式不同）】。
- **4 px 墙弹**：墙上没有尖刺时，间隙 4 px 也能墙弹，可以避开墙面上贴着的危险物（后续章节的刺球）。
- **冲刺后靠近**：冲刺开始时离墙太远（> 4 px）也没关系，冲刺结束后在 F15–F20 内水平靠近到 4 px 以内再按跳。
- **带刺墙弹**：墙面有朝向自己的尖刺时，5 px 容错失效（只剩 2 px），而尖刺区域本身是 3 px 宽。冲刺中 vx = 0，按"vx ≥ 0 即致死"（以朝左尖刺为例）会死；冲刺结束后按离墙方向，vx 变为离墙方向（不再满足致死条件），这时可以与尖刺区域重叠并在 F15–F20 内墙弹。对竖直位置要求很精确【原理已由代码核实；具体位置要求（未核实）】。
- **墙弹取消（wallbounce cancel）**：墙弹在帧 W 设置了 0.25 s 的可变跳。如果在 W+1 或 W+2 开始新的冲刺，冲刺期间计时器照走（冻结帧不走）；新冲刺在 F14 结束时设 AutoJump 为真，于是 F15（和 F16）里可变跳仍然有效，把 vy 钳到 ≤ −160（+平台加成）【代码已核实：冲刺开始不清零可变跳计时】。效果：冲刺结束后再多 1–2 帧 −160 的上升。斜下冲刺接墙弹取消时，F15–F16 不下降，水平速度保留。SJ 说"墙弹的恒定上升持续 18 帧"，就是起跳帧 + 冲刺 15 帧（含 3 冻结帧）+ 2 帧【与代码一致】。
  - **前置**：需要第二次冲刺。冲刺冷却要求 W+1 ≥ 前一次冲刺的 F15，即墙弹在 F14 或之后；还要有可用的冲刺次数（本三章需要吃水晶补冲刺）。
  - **输入**：`["1,U,X", "3,U", "10,U", "1,J", "1,R,D,X", ...]`（F14 墙弹，下一帧冲刺；需要先补回冲刺）。
- **本轮章节**：△ / ✓（墙弹取消需水晶）/ ✓（同）
- **来源 / 核实**：SJ Grandmaster Gym "Wallbounce Leniency"、"Spiked Wallbounce"；SJ Library "Collision Leniency"；【代码已核实】，带刺部分为推断。

### 4.4 中性跳（Neutral jump，neutral，无方向蹬墙，"牛抽奖"）

- **作用**：不按水平方向、不按抓，从墙上蹬跳：vx = 130 离墙，**不强制水平输入**，之后立即按回墙的方向；循环即可无体力上墙。中性跳离墙的距离固定，也常用来做像素级定位。
- **前置**：StNormal（空中或贴墙下滑），间隙 ≤ 2 px；不按抓或不朝墙（否则变成爬墙跳）；攀爬状态里不按方向按跳是**爬墙跳**（耗体力），所以要先松开抓。
- **输入**（右侧墙）：`["1,J", "11,R,J", "<k>,R", "1,J", ...]`。
- **结果**【由规则推算】：按满跳的循环约 26 帧上升约 19 px，约 **43.5 px/s**。攀爬是 45 px/s 但耗体力，中性跳不耗体力。
- **本轮章节**：✓ / ✓ / ✓
- **来源 / 核实**：SJ Advanced Gym "Neutral Jump"；celeste.ink；BWIKI（无体力上墙）；NamuWiki；【代码已核实】（蹬墙跳只在起跳时 moveX ≠ 0 才强制方向）。

### 4.5 偷体力抓跳（Wallboost）、超频（Overclock）、无体力攀爬、半体力攀爬

- **作用**：无方向的爬墙跳之后，在窗口内按离墙方向，爬墙跳"变成"蹬墙跳：vx = 130 离墙，退还 27.5 体力。效果相当于从更高处起跳的免费蹬墙跳。
- **规则**【代码已核实】（`player_physics.md` §5.10）：爬墙跳在帧 C、moveX = 0 → 窗口 0.2 s。第 C+1…C+12 帧的检查读的是**上一帧**的 moveX，所以在 **C+1…C+11 共 11 帧**内按离墙方向，下一帧生效。窗口内"疲劳"判定用的体力额外加 27.5。
- **超频（overclock）**：退还不受 110 上限限制。地面上处于攀爬状态时爬墙跳不耗体力，之后离地再触发偷体力 → 137.5；或在爬墙跳后、退还前吃水晶（先补满 110 再 +27.5）。在地面上时每帧都会把体力重置为 110，所以退还必须发生在离地之后。
- **用途**：代替中性跳无体力上墙（尽早偷体力，不按上）；把水平的平台加速换成 130；快速重新抓住坠落块。
- **半体力攀爬（half stamina climbing，TAS 级）**：偷体力后约 2 帧内人仍离墙足够近，可以再爬墙跳（+40 朝墙），用一次爬墙跳的体力换两次的高度（未核实）。
- **输入**（攀爬在右墙上）：`["1,G,J", "1,L,J", "10,J"]`。C 帧爬墙跳（无方向），C+1 按 L，C+2 生效。
- **本轮章节**：✓ / ✓ / ✓
- **来源 / 核实**：SJ Grandmaster Gym "Wallboost"（11 帧窗口、overclock，与代码一致）；celeste.ink（138，代码 137.5）；BWIKI（偷体力，"10 帧"有误差）；【代码已核实】。

### 4.6 体力管理（Stamina）与爬墙跳连发

- **规则**（`player_physics.md` §1.4、§9）：满 110；向上爬 45.45/s；抓着不动 10/s；向下爬不耗；空中爬墙跳 27.5（地面上不耗）；体力 < 20 为疲劳，不能**开始**抓墙，但已在墙上可以继续，可以爬墙跳；体力 ≤ 0 掉下。蹬墙跳、中性跳、贴墙下滑都不耗体力。
- **爬墙跳连发**：在 StNormal 里，上升中仍在墙边 2 px 内、按住抓、朝墙时，可以再爬墙跳（不需要先抓上墙）。harness 两次按跳之间至少松开 1 帧。

- **本轮章节**：✓ / ✓ / ✓
- **来源 / 核实**：SJ Library "Stamina"；【代码已核实】。

### 4.7 踩刺边跳（Corner jump）、五跳（5-jump）、六跳（6-jump）

- **作用**：从墙的最顶角起跳，比"爬到顶后被挡住"的位置更高，因此能越过更长的、顶部带刺的距离。
- **规则**【代码已核实】：
  - 蹬墙跳/爬墙跳只要碰撞箱平移 3 px 后与墙重叠 ≥ 1 px 即可；而攀爬到墙顶时，如果翻墙被挡（墙顶朝 Facing 方向 8 px 内有朝上/左/右的尖刺，或头顶 6 px 内有实心物），向上爬会停在"手部够不到"的位置，那里的碰撞箱底部比墙顶低好几 px。
  - **五跳**：爬到顶 → 爬墙跳 → 下落时缓冲第二次爬墙跳：第一帧满足"重叠 ≥ 1 px"时就起跳（碰撞箱底部只比墙顶低 1 px）→ 起点更高。也可以用中性跳从合适高度跳进墙角，只用一次爬墙跳。
  - 同理可以在墙顶角缓冲**蹬墙跳**（远离墙）换水平距离。
  - **六跳**：带着水平速度做五跳，触发抓角加速（5.2），多出 +40。
  - SJ 的"踩刺边跳"利用的是受击箱比碰撞箱底部短 2 px：碰撞箱已经够到墙（可蹬）时，受击箱还碰不到墙顶的尖刺。具体几何（未核实）。

## 5. 角与碰撞类

### 5.1 墙角修正（Corner correction）

规则表与核实见 `mechanics.md`（Corner Correction）。要点：
- 水平冲刺撞墙：上下各最多 4 px（先试向下）。
- 向上顶到角：左右最多 4 px；冲刺攻击中且几乎没有水平速度（正上冲刺）时最多 5 px。不冲刺也有效。
- 不是从地面开始的冲刺落地：可以向左右最多 4 px 滑下边缘。
- 只朝运动方向修正（vx ≈ 0 时两边都试，左优先）。
- 修正后会碰到尖刺时不修正。
- 本三章：✓ / ✓ / ✓。

### 5.2 抓角加速（Cornerboost，CB，"cb"）及全部变体

- **作用**：带着水平速度在墙顶角附近爬墙跳。爬墙跳**不覆盖**水平速度，并加 +40；若已撞墙，"撞墙速度保留"会在越过墙角后恢复原速度。同时取消冲刺。
- **前置**【代码已核实】：
  - 按住抓、朝向墙（Facing = 墙侧）、体力 > 0（疲劳也可）、墙在 2 px 间隙内、能起身、墙侧 3 px 内没有禁止攀爬的边缘。
  - 土狼计时 ≤ 0：在地面或土狼时间内按跳会先变成普通起跳。地面冲刺时会先变成 super。所以要在空中做。
  - 若人在下落（vy ≥ 0）且间隙 ≤ 1 px，按住抓会先**抓上墙**（vx 清零）。所以要在上升中做，或在间隙恰好 2 px 时做（见"向下抓角"）。
- **撞墙速度保留**（`player_physics.md` §6.3）：水平撞墙时记下原 vx，之后 4 帧（0.06 s）内每帧检查，若碰撞箱沿原方向 1 px 处已无实心物（越过了墙角），vx 恢复为原值。
- **两种情形**：
  1. 先进入 2 px 内、尚未撞墙时爬墙跳：vx = 原速 + 40（例：水平冲刺 240 → 280；hyper 325 → 365；gultra 390 → 430）。之后若撞墙，也会在越过墙角时恢复到 原速 + 40。
  2. 先撞墙（vx = 0）、下一帧才爬墙跳：vx = 0 + 40，随后保留机制把 vx 恢复为**撞墙前的原速**（没有 +40）。前提是爬墙跳后剩下的检查帧内越过墙角：起跳时碰撞箱底部大约要在墙顶以下 5–7 px 以内【由规则推算】。
  - 速度 > 180 px/s（每帧 > 3 px）时，可能一步就从间隙 ≥ 3 跨到撞墙，跳过"2 px 内"的那一帧，变成情形 2（celeste.ink："超过 180 不保证"，与代码一致）。SJ 说"原版抓角加速会因初始水平位置而失败"，就是这个原因【与代码一致】。
- **输入**（水平冲刺接抓角）：`["1,R,X", "3,R", "<k>,R", "5,R,G,J", "11,R,J"]`。按住抓只覆盖起跳前后几帧；之后松开抓，以免下落时抓上墙。
- **变体**（规则相同，条件不同）：
  - **斜向接近**：斜上冲刺撞进墙角（SJ Expert）。
  - **带刺抓角（spiked cornerboost）**：墙顶或墙面有尖刺。受击箱比碰撞箱底部短 2 px；尖刺按运动方向判定（运动方向与刺尖同向时不死）（推断）。
  - **无冲刺 / wavedash 接抓角**：跳起后松开再按跳做爬墙跳；无冲刺时从跑速 90 起：90 + 40 = 130。
  - **双重抓角（double cornerboost）**：第一次爬墙跳后仍未撞墙、仍在 2 px 内时，再爬墙跳一次，再 +40。需要水平速度较低：celeste.ink 说 ≲ 144，BWIKI 说 ≤ 100（未核实）。harness 两次按跳之间至少隔 1 帧。
  - **向下抓角（downward cornerboost）**：下落中做时，间隙 ≤ 1 px 会先抓上墙、丢掉速度，所以必须恰好离墙 2 px【代码已核实】。
  - **反向抓角（reverse cornerboost，RCB，反 cb）**：墙在身后。按向墙的方向（Facing 转向墙）+ 抓 + 跳 → 爬墙跳，vx 保留但 +40 朝墙 → 运动方向上 −40。常用来取消斜上冲刺并保留大部分速度。
  - **中性反向抓角（neutral RCB）**：起跳帧朝向墙但 moveX = 0 → 没有 −40；但会开启 11 帧偷体力窗口，其间一旦按运动方向（离墙），vx 会被设为 130。所以要 11 帧不按方向，空中减速变为 10.833/帧。
  - **消失方块抓角（disappearing block cornerboost）**：方块（磁带块、门等）在爬墙跳后立刻消失，不会撞上，保留 原速 + 40。
- **本轮章节**：✓ / ✓ / ✓（序章用无冲刺版）
- **来源 / 核实**：SJ Expert Gym "Corner Boost"；celeste.ink（全部变体）；BWIKI；【代码已核实】。BWIKI 写"靠近墙 4 像素内"，代码是间隙 ≤ 2 px【社区说法与代码不符】。

### 5.3 咖啡跳 / 墙角踢（Corner kick，cornerkick，coffee jump）

- **作用**：从下方经过天花板（或悬出部分）的下角时，向上顶角修正把人挪到下角外侧，紧贴上方的墙面，立刻从这面墙蹬出（用掉"下角"提供的额外距离）。
- **规则**【代码已核实】：上升中顶到角时，若向运动方向（或 vx ≈ 0 时两侧）挪 ≤ 4 px 就能越过，直接挪过去，不损失速度。之后若这面墙在 2 px 间隙内，按跳即蹬墙跳。墙面上有尖刺时，只要运动方向与刺尖同向就不会死。
- **变体**：中性墙角踢（不按方向，水平距离小）；无冲刺墙角踢（两次跳很近，harness 必须隔 1 帧松开）；蹲冲墙角踢（下蹲冲刺从角下穿过，按跳时需要能起身）。
- **输入**：`["...", "5,R,J", "11,R,J"]`（在经过角之前缓冲跳）。
- **本轮章节**：✓ / ✓ / ✓
- **来源 / 核实**：SJ Grandmaster Gym "Corner Kick"；celeste.ink（Cornerkick，别名 coffee jump）；BWIKI；【代码已核实】。

### 5.4 碰撞箱、方向性尖刺与贴刺跳（Hitboxes / Directional spikes / Spike jump）

- **规则**【代码已核实】（`entities.md` Spikes、`README.md` §4）：
  - 尖刺只在"受击箱重叠且朝刺尖反方向运动"时致死：朝上尖刺 vy ≥ 0 且受击箱底边 ≤ 尖刺底边；朝下 vy ≤ 0；朝左 vx ≥ 0；朝右 vx ≤ 0。运动方向与刺尖同向时可以穿过或擦过。
  - 受击箱比碰撞箱底部短 2 px：脚离朝上尖刺的底座 ≥ 1 px 就不会碰到。
  - 站地时碰撞箱与任何尖刺重叠，这一帧不补冲刺。所以从带刺表面起跳永远补不回冲刺。
- **贴刺跳（spike jump）**：带刺的表面向你移动（移动块推着尖刺）或风把你压向尖刺时，只要你在朝离开尖刺的方向运动，就可以与尖刺重叠并从那个表面起跳、蹬墙。块要移动得足够快，否则在起跳前就会死。补体力、不补冲刺。风版本需要特定的竖直位置。
- **本轮章节**：方向性尖刺 ✓ / ✓ / ✓；贴刺跳 ✗ / △（仅当尖刺附着在会动的块上，未核实是否存在）/ △（同）；风 ✗。
- **来源 / 核实**：SJ Grandmaster Gym "Spike Jump"、Library "Hitboxes"；celeste.ink；BWIKI（踩刺跳）；方向规则【代码已核实】，移动块推刺的时序（未核实）。

### 5.5 帧与穿越（Frames / 0-framing / clipping）

- **规则**：危险物、拾取物每帧只在移动后的位置检测一次（`player_physics.md` §3 第 32 步）；实心物逐像素检测。所以速度足够高时（每帧位移 > 危险物厚度，尖刺 3 px），可以跳过薄危险物而不触发。反过来，若某个动作需要在某个位置的那一帧执行，而高速下没有任何一帧落在那个位置，这个动作就做不成（"被 0 帧了"）。

## 6. 实体类技巧

### 6.1 机关加速（Block boost / Liftboost）、延迟机关加速、多重机关加速（Multiboost）

- **规则**【代码已核实】（`player_physics.md` §7）：
  - 移动的实心物或单向平台在推/载你时写入平台速度；起跳类函数和冲刺开始时都会 `速度 += LiftBoost`（水平截到 ±250，垂直只取向上且 ≥ −130，**没有向下加成**）。
  - hyper 把加成也乘上：水平 ×1.25、垂直 ×0.5。最大加成 hyper = (325 + 312.5, −52.5 − 65) = (637.5, −117.5)；最大 super (510, −235)；最大墙弹 (420, −290)；最大普通跳 vy = −235。
  - 蹬墙跳时如果自身平台速度为 0，改用所蹬那面墙记录的平台速度；但墙通常在自己更新末尾清零，所以不一定拿得到（推断）。缓冲蹬墙跳时可能在尚未接触墙时就起跳，因此拿不到加成（SJ Library）。
- **延迟机关加速（delayed block boost / momentum carrying）**：平台最后一次写入后，下一帧读到当前值，之后再 9 帧读到保留值。所以离开平台或平台停下后 **9 帧**内起跳或冲刺仍能拿到加成【代码已核实：0.16 s 宽限】。
- **多重机关加速（multiboost：double / triple block boost）**：同一个平台速度可以被多次加入：
  1. 起跳（第 1 次）后 9 帧内冲刺：冲刺开始时又加一次（第 2 次）。若是斜下冲刺且水平分量更快，就保留下来，可接 ultra。
  2. 在平台上 hyper → 落回平台兔子跳（hyper 兔子跳，2 次），再接斜下冲刺（3 次）。
  3. 墙弹 + 斜下冲刺（墙弹取消，4.3）。
  4. 对移动墙连续爬墙跳、中性跳 + 反向抓角，等。
- **数值**：交通块去程最高速约 π × 路径长度 px/s（`entities.md` ZipMover），即使超过 250 也截断到 250。
- **输入**（交通块上起跳后冲刺）：`["1,R,J", "1,R", "1,R,X", "3,R,D", "1,R,D", "10,R"]`。起跳后 9 帧内冲刺。
- **本轮章节**：✗（序章只有向下的巨石，没有向上或水平的加成）/ ✓（交通块）/ ✓（交通块、开关门、移动梦境块）
- **来源 / 核实**：SJ Expert Gym "Multiboost"、Library "Block Boosts"、"Delayed Block Boosts"；celeste.ink（Liftboost）；NamuWiki（Block boost，其中 825 的算式有误，按代码截断后应为 637.5）；【代码已核实】。

### 6.2 梦境块技巧（Dream block tech，2A）

规则见 `player_physics.md` §10。以下全部【代码已核实】，除注明外。

- **梦境跳（Dream jump，果冻跳）**：在出口帧 E 跳键"按下"（可提前 4 帧缓冲），且冲刺方向有水平分量 → 普通起跳：vx = 出口速度 + 40·moveX（水平穿出 240 → 280），vy = −105。竖直穿出不能梦境跳。
- **梦境双跳（Dream double jump，果冻双跳）**：梦境跳之后，出口处理又把土狼计时设为 0.1 s，所以在土狼时间内能再普通起跳一次，再 +40 → 320，vy 重置为 −105。harness：E 帧之前缓冲第一跳；E+1 松开；E+2 或 E+3（冻结帧）再按并按住，第二跳在 E+4（第一个正常帧）执行。
  - 输入：`["5,R,J", "1,R", "3,R,J", "11,R,J"]`（第一段的最后一帧是 E）。
  - 按反方向做两次跳可以在出口刹车（每跳 −40）。
- **梦境反抓（Dream grab，果冻反抓）**：出口时按住抓，并按住朝向一侧可抓墙的方向（通常是**反方向**，即梦境块本身：水平穿出时若身后 5 px 内有实心物，会先被拉回贴住）→ 直接进入攀爬。条件是冲刺方向向下或有水平分量（正上穿出不行）。
- **梦境 hyper / super（Dream hyper / super，果冻 Hyper/Super；反向梦境 hyper/super）**：出口后冻结 3 帧（E+1–E+3），E+4 起计时，土狼计时剩 0.0833。在 E+4 受理冲刺（F0），让跳在 F4（E+8）"按下"→ F4 立即 super；若 F0 下蹲 → hyper。土狼计时在 F4–F7 都 > 0，**共 4 帧窗口**（与 SJ 的"最多 4 帧"一致）。
  - 输入（从 E+1 开始）：`["4,R,D,X", "3,R", "1,R,J", "11,R,J"]`。X 在冻结帧按下并按住，E+4 受理冲刺；F0 按住 D → 下蹲；F4 起跳 → hyper。
  - 若进入梦境块时处于下蹲（下蹲冲刺进入），出口后仍蹲着；空中下蹲时开始冲刺会**先起身**，于是只能 super，不能 hyper。
  - 斜向穿出、从上下面出来时，向哪边 hyper 都可以（反向梦境 hyper）。
  - **冲刺冷却**：进入梦境块的那次冲刺冷却 12 个正常帧，出口冻结的 3 帧不算。若梦境块很短（E 距那次冲刺的 F0 不足约 14 帧），E+4 还不能冲刺。
  - 结果：梦境 hyper 325 / −52.5（比梦境跳快、低）；梦境 super 260 / −105，弧线几乎等于梦境跳，很少有用。冲刺不补回（这次冲刺用掉了出口补满的那一次）。
- **梦境墙弹（Dream wallbounce）**：进入梦境块时冲刺攻击被清零，所以出口时不能直接墙弹。原版做法是出口后（出口已补满冲刺）立即正上冲刺，再正常墙弹，同样受上面的冷却限制。celeste.ink 把"在梦境块内获得额外冲刺再墙弹"列为 mod 技巧，那一形式不收录。
- **梦境斜下穿出接落地 ×1.2**：斜下穿出后冲刺方向仍为斜下，落地触发 ultra 转换：169.7 → 203.6（推断，未实测）。
- **缓冲冲刺出梦境块**：SJ 说水平穿出时缓冲冲刺，会在离块 4 px 处冲刺（未核实）。
- **Splipped droosts**：在带刺梦境块的上角做梦境冲刺而不进入块（celeste.ink 梗名）（未核实）。
- **本轮章节**：✗ / ✗ / ✓（梦境块激活后）
- **来源 / 核实**：SJ Beginner Gym "Dream Jump"、"Dream Grab"；Expert Gym "Dream Hyper"、"Dream Super"；Grandmaster Gym "Dream Double Jump"；celeste.ink；BWIKI。

### 6.5 换房技巧（Screen transitions：补冲刺、换房墙弹 / super / hyper、Kermit dash）

- **规则**【代码已核实】：
  - 换房完成时**补满冲刺与体力**，土狼计时清零，强制水平输入清零；速度取整到整数。
  - 过渡期间 Madeline 不更新：所有计时器（冲刺攻击、可变跳、冷却）和冲刺协程都暂停，过渡结束后接着走。
  - **侧向换房**：不改状态，冲刺继续。
  - **向上换房**：vx = 0；vy 被**设为 −105**（不论原来多快），可变跳 0.2 s，AutoJump；状态设为 Normal（冲刺被结束）；冲刺冷却 0.2 s。冲刺攻击计时**不清零**。
  - **向下换房**：状态设为 Normal，vy = max(0, vy)，取消 AutoJump 与可变跳；**vx 保留**（可以用来取消 gultra 而保留速度）。
- **换房墙弹（transition wallbounce，Kermit tech）**：正上冲刺穿过向上换房，到新房间后仍在冲刺攻击中、冲刺方向仍为正上 → 在 StNormal 里贴墙按跳即墙弹。冲刺已被换房补满。
- **换房 super/hyper**：水平冲刺穿过侧向换房，冲刺状态保留；到新房间后要**落在地面上**再按跳（土狼计时被清零了）；冲刺次数已被补满，相当于免费 extended。
- **Kermit dash**：冲刺状态跨换房保留，玩家可以在冲刺方向不变的情况下继续控制（celeste.ink，niche）。
- **本轮章节**：✓ / ✓ / ✓
- **来源 / 核实**：SJ Library "Screen Transitions"；celeste.ink；BWIKI（切板）；【代码已核实】。SJ 说向上换房"只在上升速度不足时才把人往上推"，代码是无条件设为 −105，向上冲刺穿过时也会被压到 −105，而且 vx 清零【社区说法与代码不符】。

### 6.6 方块更新技巧（Reform tech：reform boost / cassette boost / reform kick）

## 7. 帧精确与高级

### 7.1 F4 特例：冲刺与跳同按 = 立即 super / hyper；F4 不能墙弹

- F4 的冲刺更新先于冲刺方向的设定执行，此时冲刺方向为零，被当作"水平"。所以只要 F4 时跳键"按下"（F0 时同按 J 并按住，缓冲覆盖 F0–F4）且土狼计时 > 0，F4 就执行 super（F0 下蹲则 hyper），水平方向取 F4 的 Facing，冲刺方向根本没被应用【代码已核实】。
- 想在地面上做向上冲刺时，跳键不能在 F0–F4 处于"按下"状态。墙弹的跳必须在 F5 之后（F4 的跳会变成普通蹬墙跳或 super）。
- 土狼时间内：在第一个空中帧起的前 4 帧内受理冲刺，F4 仍在土狼时间内。

### 7.2 落地 ×1.2 的"贴地未撞"陷阱

见 3.10：落地帧位移刚好停在地面上时，下一帧在地面上但还没有发生落地碰撞；这一帧起跳或冲刺会让这次 ×1.2 丢失（冲刺开始还会清掉斜下标记）。模拟器可以直接判断：落地那一帧是否"试图越过地面"（本帧应移像素数 > 到地面的间隙）。若不确定，在地面上停 1 帧再动作。

### 7.3 冲刺开始的贴地（gultra 的地面修正）

F0 时冲刺方向为零，算"水平"，冲刺攻击已开始；若此时离地且下方 3 px 内有地面，立即下移贴地。所以 hyper 起跳后 1–2 帧内冲刺，仍算在地面上冲刺（3.12）【代码已核实】。

### 7.4 冻结帧与 IGT

见 0.5 与 `mechanics.md` §1。对时间最优搜索的含义：同样的路线，多用冲刺不会因冻结帧增加 IGT；但冲刺的 F0 帧速度为 0，这一帧算 IGT。

### 7.5 harness 只有一个 J 键（"双键绑定"的替代）

社区的双键绑定（两个跳键交替，连续两帧都"按下"）在 harness 里不可用：两次按跳之间至少隔 1 帧松开。受影响的有：梦境双跳（利用冻结帧缓冲，可行，见 6.2）、无冲刺墙角踢、双重抓角、水面连跳（只能隔帧）。

## 附录 B. 与代码不符 / 未核实汇总

**社区说法与代码不符**（以代码为准）：
1. hyper 的 vy：BWIKI、NamuWiki 写 −55；代码 −52.5。
2. 冲刺后墙弹窗口：SJ Grandmaster 写 5 帧；代码 6 帧（F15–F20）。SJ Library 冲刺攻击一节写 6 帧，与代码一致。
3. 向上换房：SJ 写"上升速度不足才推"；代码无条件设 vy = −105、vx = 0。
4. 抓角加速距离：BWIKI 写"4 像素内"；代码间隙 ≤ 2 px。
5. 空中 super 容错：NamuWiki 写"上 1 下 3"；代码侧撞上抬最多 4 px、贴地要求间隙 ≤ 2 px、单向平台 6 px。
6. Demodash 输入：celeste.ink 写"冲刺前 4 帧内按下"；代码只看 F0 是否按住下（或 Z）。
7. 超级弹倍率：SJ/celeste.ink 写"约 1.5–2 倍"；代码在发射时按住同方向给水平 ×1.2（280 → 336）。
8. 下蹲冲刺后"抬高 2 px"（BWIKI）：代码中没有，可能是泡泡 Archie 的效果。
9. 偷体力窗口：BWIKI 写 10 帧；代码与 SJ、celeste.ink 一致为 11 帧。
10. NamuWiki 双重机关加速算例"825"算术有误；按代码截断后 hyper 加成上限为 637.5。

**未核实**：岩浆块"垂直 ×2.25"（celeste.ink）；双重抓角的速度阈值（144 / 100）；吃水晶冻结的起始帧；缓冲冲刺出梦境块的"4 px"；羽毛斜向初速是否未归一化；seeker 反弹、望远镜卡刺、熔岩攀爬、ceiling pop、bubsdrop、剧情跳过类、带水母进果冻的细节；贴刺跳在 1A/2A 是否有带刺移动块。
