## 1. 章节计时（IGT）与冻结帧

- **计时如何累加**【代码已核实】：每当关卡做一次正常的逻辑更新，章节计时就加上本帧的原始时长（RawDeltaTime ≈ 0.0166667 s）。前提是计时已经开始、章节未完成、计时没有被停止。
- **冻结帧不计时**【代码已核实】：冻结剩余时间 > 0 的帧里，引擎只做"冻结帧更新"（少数带特殊标记的实体），不调用关卡的正常更新，因此不累加章节计时。harness 的帧计数里冻结帧照算，`chapterTimeTicks` 不变。
- **会计时的情况**：暂停菜单打开期间（关卡更新里，计时累加在"是否暂停"判断之前执行）、解除暂停的过渡、换房过渡、剧情（计时开始之后）。
- **计时何时开始**：不在剧情中、Madeline 存在且未暂停计时的第一帧。
- **冻结来源与长度**（冻结时间取"现有剩余与新请求的较大者"，不叠加）：

| 来源 | 冻结 | 核实 |
| --- | --- | --- |
| 冲刺开始（时间倍率 > 0.25） | 0.05 s = 3 帧 | 代码已核实 |
| 红泡泡冲刺开始 | 3 帧 | 代码已核实 |
| 吃冲刺水晶 | 3 帧 | `entities.md`（起始帧为推断） |
| 离开梦境块 | 3 帧 | 代码已核实 |
| 撞碎冲刺砖 | 3 帧 | `entities.md`（推断：晚一帧开始） |
| 爆炸弹射（弹球、河豚） | 0.1 s = 6 帧 | 代码已核实 |
| 踩 seeker 反弹 | 9 帧（SJ） | 未核实 |

- 在冲刺水晶上开始冲刺只有 3 帧冻结（取较大者）。
- **对时间最优的含义**：冲刺、吃水晶、梦境块出口带来的冻结帧都是"免费"的实际帧。比较方案时用非冻结帧数（= IGT 帧数）。

## 2. SJ 机制库（Library）全部小节

SJ 中文名取 SJ 官方简体中文译名。"本三章"指 序章 / 1A / 2A 是否有这条规则起作用的场景（规则本身是全局的）。

### 2.1 速度（Speed）
- 单位 px/s。常用速度：跑步 90，蹬墙跳 130，斜向冲刺每轴 169.71，羽毛巡航最高 190，冲刺 240，hyper 325。【代码已核实】
- 本三章：✓。

### 2.2 帧（Frames）
- 1 帧 = 一次逻辑更新，dt ≈ 0.0166667 s（`README.md` §3）。位置每帧离散跳变。
- 危险物和拾取物每帧只在移动结束后检测一次；实心物逐像素检测。所以高速时可以跳过薄的危险物（尖刺 3 px 厚），而某些需要"某一帧恰在某处"的动作在高速下可能没有可用的帧（"被 0 帧"）。【代码已核实（检测时机，`player_physics.md` §3、§14）】
- 本三章：✓。

### 2.3 机关加速（Block Boosts）
- 起跳类函数与冲刺开始时，速度 += 平台速度。水平截断到 ±250；垂直只取向上部分，且不小于 −130；**没有向下加成**。【代码已核实】
- 普通起跳最多 vy = −105 − 130 = −235；蹬墙跳最多 vx = 130 + 250 = 380；super 最多 (510, −235)；墙弹最多 (420, −290)。
- hyper 把加成也乘上（水平 ×1.25，垂直 ×0.5）：最多 (637.5, −117.5)。【代码已核实：先加平台速度，再乘下蹲系数】
- 必须真正接触过移动块才有加成；缓冲蹬墙跳时可能在接触前就起跳，于是拿不到。蹬墙跳在自身平台速度为 0 时会改读所蹬墙记录的平台速度。【代码已核实】
- 本三章：✗ / ✓ / ✓（交通块等）。

### 2.4 弹跳（Bouncing）
- 踩河豚、冰球、seeker、雪球、Oshiro 等的顶部 → 弹跳：vy = −140，可变跳 0.2 s（前 0.1 s 即 6 帧自动保持，之后需按住跳才继续保持，共 12 帧），**vx 保留**，补满冲刺与体力，状态设为 Normal（取消冲刺）。【代码已核实】
- 所以冲刺中踩上去 = 取消冲刺并保留速度（"puffer super"：不是真 super，不能反向，不改水平速度）。弹跳没有 +40 跳跃加速。
- 本三章：✗（没有这些实体）。

### 2.5 碰撞距离容错（Collision Leniency）
- 抓墙：间隙 ≤ 1 px。蹬墙跳、爬墙跳：间隙 ≤ 2 px；在 2 px 处爬墙跳不进入攀爬状态，不会触发需要"骑乘"的机关。【代码已核实】
- 墙弹：间隙 ≤ 4 px（墙上 5 px 处有朝向自己的尖刺时退化为 2 px）。【代码已核实】
- 冲刺贴地：冲刺攻击中、方向水平、离地且脚下 ≤ 2 px 有地面或单向平台 → 贴下去（让空中 super 更宽松）。【代码已核实】
- 本三章：✓。

### 2.6 墙角修正（Corner Correction）

【代码已核实】（`player_physics.md` §6.1–§6.2）

| 情况 | 最大修正 | 条件 |
| --- | --- | --- |
| 纯水平冲刺撞墙 | 上下各 4 px，先试向下 | 冲刺状态（含红泡泡）；vy 恰为 0；修正后受击箱不碰尖刺 |
| 上升顶到天花板角 | 左右 4 px；冲刺攻击中且 \|vx\| < 0.01 时 5 px | 不需要冲刺；只朝运动方向（vx ≈ 0 时两边都试，左优先） |
| 落地（冲刺不是从地面开始的） | 左右 4 px，滑下边缘 | 冲刺状态；只朝运动方向 |
| 水平冲刺脚陷入单向平台 | 抬升 ≤ 6 px | 单向平台抬升而非角修正，同样让空中 super 更宽松 |

- 修正方向不能与运动方向相反：例如向左下冲刺进地面时，不会被修正到右边；斜上冲刺顶到角时，只在远离墙的方向修正。
- 向下运动时先与实心物碰撞（并修正），尖刺检测在本帧移动结束后才做，所以向下冲刺即使地面上有尖刺也能被修正进缝里（只要冲刺没在落地前结束）。
- 本三章：✓。

### 2.7 狼跳（Coyote Time）
- 离开地面后 5 个正常帧内可以普通起跳，也可以 super/hyper；冻结帧不消耗；起跳后清零。土狼时间内不会站地补冲刺，所以离地后才到 F10 的 super/hyper 不算 extended。【代码已核实】
- 其他来源：碎裂平台在脚下消失（等同走下平台）、水平或斜向穿出梦境块（0.1 s）、岩浆块把人甩开（0.1 s）。【代码已核实（梦境块、岩浆块）】
- 利用土狼时间：走下平台进泡泡，同时按冲刺和跳，可以立刻 super/hyper（泡泡，后续章节）。
- 本三章：✓。

### 2.8 下蹲（Crouching）
- 碰撞箱高 11 → 6，受击箱高 9 → 4；地面下蹲时不能走动，可以斜下冲刺移动并保持下蹲。【代码已核实】
- 下蹲碰到地面弹簧会保持下蹲被弹起（弹簧只在移动时临时换成站立碰撞箱）。【代码已核实】
- 开始下落时自动起身；例外是仍在土狼时间内，或头顶放不下站立碰撞箱。【代码已核实】
- 下蹲时不能抓墙，但能爬墙跳；蹬墙跳会起身。下蹲且不在冲刺时不能拾取物品（所以 ultra 后要拿水母时不要蹲跳）。【代码已核实】
- 下蹲时不受水平风推动，起身后几帧内仍免疫（未核实；本三章无风）。
- 冲刺被地面起跳取消时，**是 super 还是 hyper 只看是否下蹲**，不看冲刺方向。水平冲刺钻进 1 格高的缝会自动下蹲，之后的起跳就是 hyper（起跳那一刻要能起身）。【代码已核实】
- 本三章：✓。

### 2.9 灰砖（Crumble Blocks）
- 站在上面约 36 帧（0.6 s）碎；抓侧面约 60 帧（1 s）碎；落上去立即跳走约 12 帧（0.2 s）碎。消失 2 s 后，等没有任何 Actor 或实心物与它重叠时才恢复。可以在它碎之前跳、wavedash。数值与 `entities.md` 一致（站立 0.2–0.6 s 取决于何时离开）。
- 本三章：✗ / ✓ / ✓。

### 2.10 冲刺状态保留（Dash Attack）
- 冲刺攻击在冲刺状态结束后还持续 6 帧（F15–F20）。冲刺砖、梦境块、冲刺类机关、墙弹 5 px 检测都看它。【代码已核实】
- 冲刺攻击期间如果先抓墙或先起跳（缓冲蹬墙跳），就能接触冲刺类机关而不触发它：起跳会清零冲刺攻击；抓墙会直接贴上墙，不经过碰撞回调。【原理已由代码核实】
- 本三章：△ / ✓ / ✓。

### 2.11 冲刺冷却（Dash Spacing）
- 一次冲刺共 15 个实际帧（含 3 个冻结帧），下一次最早在第 16 帧（F15）。冲刺被 wavedash、蹬墙、梦境块、弹簧等取消后，冷却照样从 F0 算。【代码已核实】
- 水平冲刺结束后速度是 160，正上冲刺结束后是 −120，所以拉开冲刺间隔能走得更远、更高。
- 本三章：△ / ✓ / ✓。

### 2.12 冲刺速度（Dash Speed）
- 冲刺 240，斜向每轴 169.71；同向更快的原水平速度会保留；正上、水平、斜上冲刺结束时被重置，斜下、正下冲刺结束不重置（ultra 的基础）。【代码已核实】
- 冲刺结束后水平速度是 160，再按普通规则减速。斜下冲刺在地面上结束 → 160 → 失败 hyper（`techniques.md` 2.9）。
- 本三章：△ / ✓ / ✓。

### 2.13 下落方块（Falling Blocks）
- 站在上面约 0.6 s 后坠落；默认抓住侧面也会触发（可按块关闭）；踩到它上面的弹簧或被其他块撞到也会触发。下落最高 160 px/s；触发后一旦失去接触就立刻坠落；坠落时撞碎路径上的冲刺砖（包括普通冲刺撞不碎的那种）。可以在它开始下落前落地、起跳、wavedash。数值以 `entities.md` 为准。
- 本三章：✗ / ✓ / ✓（视地图）。

### 2.14 下落速度（Falling Speed）
- 重力每帧 +15，下落上限 160；下落速度已到 160 时按住下，上限每帧 +5，最高 240，松开后回到 160。【代码已核实】
- 拿着水母时：下落 40；按上 24；按下 120。【代码已核实】
- 贴墙下滑：上限在 72 帧内从 20 线性升到 160，所以速度每帧约 +1.94（SJ 写 1.9）；快速下落中开始贴墙，会先减速到当前上限；上升中贴墙不影响 vy。【代码已核实】
- 本三章：✓。

### 2.15 羽毛加速（Feather Boosts）
- 羽毛变身完成时，初速 = 250 × 当时的方向输入（无输入则沿朝向）；之后速度以每帧 16.7 趋向目标速度（按住方向时 140 → 190，不按 91），所以开头一小段比巡航快。斜向输入时初速是否更大取决于方向向量是否归一化（未核实）。【代码已核实（250、目标速度）】
- 本三章：✗。

### 2.17 摩擦力（Friction）
- 速度高于 90 时：空中按前进 4.333/帧；空中不按或反按 10.833；地面按前进 6.667；地面下蹲 8.333；地面不按或反按 16.667（SJ 写 4.3 / 10.8 / 6.7 / 8.3 / 16.7）。【代码已核实】
- 本三章：✓。

### 2.18 碰撞箱（Hitboxes）
- Madeline 有两个箱：碰撞箱（与地形碰撞）8×11，受击箱（与危险物、泡泡等）8×9，底部短 2 px；下蹲时 8×6 / 8×4（`README.md` §4）。【代码已核实】
- 受击箱较矮，所以脚可以碰到实心物而不碰危险物：踩刺边跳、带刺抓角都利用这一点。
- 尖刺按运动方向致死（`entities.md` Spikes）。刺球（后续章节）恰好 2 格宽、不到 2 格高，网格对齐的刺球列之间有一条与下蹲受击箱同高的缝；刺球之间填充的"汁"不致死（未核实，本三章无刺球）。
- 电（后续章节）的危险区每边比贴图小 1 px（未核实）。可抓物品有一个大的抓取箱和一个小的碰撞箱（未核实）。弹簧的碰撞箱比贴图大（16×6），擦过墙角也能碰到（`entities.md`）。
- 本三章：✓。

### 2.19 预输入（Input Buffering）
- 跳、冲刺、蹲冲的缓冲都是 5 帧（按下帧 + 4），只在按住期间有效，冻结帧也消耗缓冲（`input.md` §2）。【代码已核实】
- 用法：落地前缓冲跳；没有冲刺时缓冲冲刺，在落地补冲刺或吃水晶后立刻冲；缓冲爬墙跳，在上升中一路爬墙跳而不抓墙（不触发机关）；缓冲冲刺接弹簧（弹簧补满冲刺）。
- SJ 提醒：用缓冲做像素级卡位的设置在不同游戏速度下会失效（冲刺长度随之变化）。
- 本三章：✓。

### 2.20 跳跃加速（Jump Boosts）
- 起跳时按住左或右，水平速度 ±40。适用于所有普通起跳：地面跳、土狼跳、爬墙跳越过墙角、梦境跳、空中跳（jump refill，mod）。抓角加速和梦境双跳就是靠它拿速度。按反方向可以减速。【代码已核实】
- 轻点跳、频繁落地可以在长距离上近似保持速度（空中摩擦小于地面）。
- 本三章：✓。

### 2.21 跳跃高度控制（Jump Control）
- 地面起跳后上升速度恒定 12 帧（0.2 s）；期间松开跳就立刻开始受重力。super、hyper、墙弹等同样可以靠松开跳缩短（"受控 hyper"）。
- |vy| < 40 时按住跳重力减半（7.5/帧）→ 快速松开再按住跳，可做又低又远的"浮空跳"。【代码已核实】
- 本三章：✓。

### 2.22 延迟机关加速（Delayed Block Boosts / Momentum Carrying）
- 平台最后一次写入平台速度后，Madeline 在下一帧读到当前值，再之后 9 帧读到保留值（宽限 0.16 s）。所以离开平台或平台停下后 9 帧内起跳或冲刺仍拿到加成。例如交通块停下后立即冲向墙并蹬墙，仍能得到交通块的速度。【代码已核实】
- 本三章：✗ / ✓ / ✓。

### 2.23 房间切换（Screen Transitions）
- 过渡期间不能控制，Madeline 不更新（计时器、冲刺协程暂停）；动量保留（结束时取整到整数）；完成时补满冲刺与体力，土狼计时清零。【代码已核实】
- 向上换房：vx = 0，vy **设为 −105**（不论原来多快），可变跳 0.2 s，状态设为 Normal，冲刺冷却 0.2 s；冲刺攻击计时保留 → 换房墙弹。SJ 写"上升速度不足时才往上推"【社区说法与代码不符】。
- 侧向换房：冲刺状态保留 → 换房 super/hyper（到新房间后要落地再跳）。
- 向下换房：状态设为 Normal，vx 保留，vy ≥ 0。
- 本三章：✓。

### 2.24 体力值（Stamina）
- 满 110；抓着不动 10/s；向上爬 45.45/s；向下爬不耗；空中爬墙跳 27.5（地面上不耗）；蹬墙跳、中性跳、贴墙下滑（无论是否按抓）都不耗。【代码已核实】
- 体力 < 20（SJ："到 20 时"）为疲劳：已经抓着可以继续抓，可以爬墙跳，可以触发机关；不能开始抓墙；不能拾取物品。≤ 0 为力竭：不能抓、不能爬墙跳。【代码已核实（拾取要求不疲劳）】
- 抓着不动 9 s 疲劳、11 s 力竭；连续向上爬 1.98 s 疲劳、2.42 s 力竭，最多爬约 108.9 px（13.6 格）；4 次爬墙跳约 106.9 px（SJ），体力未空时还能再爬一段或再爬墙跳。
- 风对攀爬的影响（向下风减慢爬升、向上风让爬墙跳更有效）本三章不涉及（未核实）。
- 本三章：✓。

### 2.25 Ultra 机理（Ultra Mechanics）
- 两个机制叠加【代码已核实】：(1) 斜下冲刺在空中结束不重置速度；(2) 斜下冲刺标记仍在时落地，水平速度 ×1.2。所以 hyper 只能给固定速度，连续 ultra 可以无限加速。
- 冲刺若在落地前没结束：冲刺在地面上结束 → 速度变 160；冲刺结束前起跳 → wavedash（hyper）。最小高度约 3.5 格（28 px）。
- 跳不是必须的，但起跳 +40，而且空中损失比地面小。地面上不要按下（下蹲摩擦更大）。
- **1 px 陷阱**：可能出现"已经在地面上（可以起跳）但还没发生落地碰撞"的一帧；这一帧起跳（含缓冲跳）就拿不到 ×1.2。所以落地后至少滑 1 帧（`techniques.md` 3.10、7.2）。
- 本三章：△ / ✓ / ✓。

### 2.26 水（Water）
- 水面上可以缓冲起跳，即使水里有危险物；但不补冲刺。【代码已核实（游泳状态里，水面附近按跳 = 普通起跳）】
- 水中冲刺**不消耗冲刺次数**（拿着双冲刺时可以一直保持 2 次），从水里冲出来也不消耗；游泳时持续补冲刺。【代码已核实】
- 水中可以墙弹、super、hyper（下方有地面、旁边有墙）。冲刺速度在水中 ×0.75。【代码已核实（×0.75）】
- 水面上每次起跳 +40，可以每次重新按下就跳（harness 只能隔帧按）。
- 本三章：✗。

## 3. 后续章节实体的交互规则（本轮章节用不到）

以下规则支撑 `techniques.md` §6.7 的技巧。核实来源为反编译代码。

### 3.1 可拾取物（Theo 水晶、水母 Jelly）
- **拾取**【代码已核实】：普通状态下按住抓、不疲劳、不下蹲、碰到物品的抓取范围即拾取。冲刺状态下要求冲刺方向已设定（F5 起）、按住抓、不疲劳、能起身。
- **拾取过程**：进入拾取状态，速度清零，约 0.16 s（约 10 帧）里不移动；结束时恢复拾取前的速度（vy 截到 ≤ 0）和可变跳计时，回到普通状态。所以**冲刺中拾取 = 取消冲刺并保留冲刺速度**（不会被冲刺结束重置），这是 regrab、lift、vator、Theo/水母 ultra 的基础。
- **水母额外上升**：若距离最近一次冲刺开始、super 或墙弹不到 0.55 s，且那次的方向向上，则拾取结束时 vy ≤ −240 × |方向的竖直分量|：正上冲刺/墙弹 −240，斜上冲刺/super −169.7，hyper −133.4；否则若正在上升，vy ≤ −105。普通起跳和蹬墙跳会清掉这一窗口。
- **拿着时**：不能抓墙、不能爬墙跳，可以蹬墙跳（拿水母时蹬墙后强制方向 0.26 s）；Theo 让跑速上限变为 70；水母让空中跑速上限 108、空中加速减半，下落 40（按上 24、按下 120）。
- **投掷**：拾取后 0.35 s 内不能扔。松开抓时，若按住下 → 竖直放下（中性下放）；否则向朝向扔出，同时 Madeline 的 vx += 80 × 朝向的反方向（反丢加速的来源）。地面上按住下 → 放下并下蹲。
- 物品被抓着时，它的小碰撞箱不与地形碰撞，但仍会被 seeker/Theo 屏障挡住（SJ，未核实）。

### 3.2 泡泡（Booster，绿 / 红）
- **进入**【代码已核实】：速度清零，进入泡泡状态，补满冲刺与体力（`player_physics.md` §11）；每帧以 80 px/s 向"泡泡中心 + 方向输入 × 3 px"移动。
- **发射**：按冲刺或蹲冲 → 立即发射（快速启动），否则 0.25 s 后自动发射；**不消耗冲刺次数**；绿泡泡进入冲刺状态（同普通冲刺，含冻结、super/hyper/墙弹规则），红泡泡进入红泡泡冲刺。方向取冻结结束后第一帧的瞄准。
- **下蹲**：在泡泡里按蹲冲发射 → 下蹲冲刺。若进入泡泡时已经下蹲，绿泡泡发射时会因"空中且已下蹲"而起身，所以下蹲进泡泡后不能下蹲冲刺出去。红泡泡开始时总会起身。
- **Archie**：泡泡把 Madeline 的碰撞箱中心对准泡泡中心；下蹲碰撞箱的中心更低，所以下蹲进入时人的位置高约 2–3 px，发射轨迹随之偏移。
- **红泡泡冲刺**：每帧可冲刺出去（消耗冲刺）；方向水平时土狼计时 > 0 可 super/hyper；正上时可墙弹；其他方向可蹬墙或爬墙跳。撞墙后进入 0.1 s 的硬直（速度以 800 px/s² 趋向 0，期间可跳、可冲刺）。

### 3.3 羽毛（Feather / StarFly）
- 【代码已核实】变身期间速度以 1000 px/s² 趋向 0；完成后补满冲刺与体力，初速 250 × 方向输入，持续 2 s（最后 0.5 s 警告）。
- 飞行：方向每秒最多转 5.585 rad（每帧约 5.3°）；按住与运动方向夹角约 63° 以内的方向时目标速度从 140 升到 190（1 s），不按时 91。
- 撞到实心物：飞行剩余 < 0.2 s 时直接停；否则该轴速度 ×(−0.5)（羽毛反弹）。
- 离地 3 px 内按跳 → 普通起跳，保留羽毛的水平速度（"feather super"）；贴墙按跳 → 蹬墙跳；按住抓且旁边可抓 → 攀爬；可以冲刺出去。

### 3.4 爆炸弹射（弹球 Bumper、河豚 Puffer 爆炸；seeker 复活爆炸）
- 【代码已核实】冻结 0.1 s（6 帧）。方向 = 从爆炸点指向身体中心，再吸附：接近正上（点积 ≤ −0.7，且允许向上吸附）→ 正上；竖直分量在 −0.55…0.65 之间 → 纯水平。河豚只给水平方向。
- 速度 = 280 × 方向；若 vy ≤ 50，vy = min(−150, vy) 并设 AutoJump。
- **超级弹**：发射时按住与弹射同向的水平方向 → vx ×1.2（336）；若发射那一刻没按，下一个正常帧（冻结之后）补判一次。补满冲刺与体力，冲刺冷却 0.2 s。
- 弹射状态：vy 以 450（上升时）/ 225（下降时）px/s² 趋向 160，vx 以 200 px/s² 趋向 0，速度大小 < 220 时回到普通状态；期间可冲刺、可拾取。
- SJ / celeste.ink 写"约 1.5–2 倍"【社区说法与代码不符：代码为 ×1.2】。

### 3.5 云（Cloud，蓝 / 粉）
- 【代码已核实】站上云（vy ≥ 0）时，云以 180 px/s 向下，再以 1200 px/s² 减速并回升；回升期间云以平台速度 −220 移动（起跳只取到 −130，即 vy = −235）。
- 云回到起点上方、速度回升到 ≥ −100 时，若人仍站在云上且 vy ≥ 0，直接把人的 vy 设为 −200（不跳也有的小弹）。粉云此时消失，2.5 s 后恢复。
- 刚落上就跳：云还在往下，平台速度向下，没有加成。

### 3.6 岩浆块 / 冰块（Bounce block，core block）
- 【代码已核实】站在顶上（vy ≥ 0）或攀爬在侧面会让它蓄力，然后朝远离你的方向弹出 24 px。弹完时若你仍站在或抓在上面：状态设为 Normal，速度设为方块速度（大小 ≤ 200，水平 ×0.75），并给 0.1 s 土狼时间。随后方块碎裂，等不再有东西与它重叠时才恢复。
- 所以碎裂后的 5 帧内可以起跳、super、hyper，并叠加平台速度（宽限 9 帧）。F4 立即 hyper 要求在前 4 个土狼帧内冲刺，这就是 SJ 说的"core hyper 精确窗口 4 帧"。冲太晚会变成带加成的斜下冲刺；冲太早方块还没碎，会干扰 hyper。

### 3.7 月亮块（Floaty space block）
- 冲刺撞到它（冲刺攻击中）时，整组块沿冲刺方向被推开，最多约 8 px，带缓动，推力以每秒 1.5 衰减；有人站上会下沉。块移动时给骑乘者平台速度，于是可以起跳拿加成（moonboost）。【部分核实】

### 3.8 磁带块（Cassette block，本三章只在隐藏磁带房间）
- 【代码已核实】要变为实心时，若与 Madeline 重叠，先尝试把她直接上移 1–4 px；挪不开则本帧整组保持不实心（附着物也不启用），下一帧再试。变实心的同一帧块上移 1 px，给骑乘者 −60 px/s 的平台速度。（节拍见 `entities.md`。）
