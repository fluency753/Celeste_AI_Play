# Agent 文档目录

- `shared/`：探索和速通共用的操作与观测资料。`data.md`、`tools.md` 为短入门，`tools/` 为按工具组织的完整参考。
- `explore/`：探索模式的索引、基本游戏规则和尝试提示，不包含速通知识与路线。
- `speedrun/`：速通模式的物理、技巧、实体、机制与搜索资料。
- `reference/`：本机生成的社区原文，属于速通知识，保留既有生成位置，不入库。

主控按模式和权限生成只读 `/kb` 视图：共享文档固定在 `/kb/shared/`，当前模式的索引与资料放在视图根目录。探索不挂速通知识，除非用户明确开放指定文件。

准备阶段的必读清单由文档清单生成，完整工具参考按需阅读。文档中的 `{tool:act}` 等标记按实际执行器展开；协议字段、路径和代码示例不做猜测替换。

旧本机知识库覆盖和权限路径继续识别；新旧路径存在不同修改时明确报冲突。`local/` 的用户文件与社区原文不自动迁移或改写。
