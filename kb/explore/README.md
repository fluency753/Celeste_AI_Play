# 新手探索资料

准备阶段只需完整读取本文件、basics.md（基本规则）、shared/data.md（坐标与观测要点）、shared/tools.md（基本操作）。以用户当前任务安排探索、研究或章节进展；游戏中通过真实尝试验证认识。原版游戏会逐步教学，留意画面中的提示；暂时不知道某个物体的用途很正常，可以在游戏中验证。

完整参考在 shared/tools/，不要求开局通读：observe.md 说明观测与分页，act.md 说明输入、TAS 和计划，cutscene.md 说明剧情与结算，files.md 说明工作区，programs.md 说明程序优化。
探索专属的尝试提示见 help/controls.md。

笔记、公开反馈和程序额度遵循本次操作指南。本模式不挂载预设模拟器文件或速通知识库，也不联网查攻略；开放的有限预测只能经本次工具按额度使用。
