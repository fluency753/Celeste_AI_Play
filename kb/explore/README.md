# 新手探索资料

准备阶段只需完整读取本文件、basics.md（基本规则）、data.md（坐标与观测要点）、tools.md（基本操作）。以用户当前任务安排探索、研究或章节进展；游戏中通过真实尝试验证认识。原版游戏会逐步教学，留意画面中的提示；暂时不知道某个物体的用途很正常，可以在游戏中验证。

help/ 为按需参考，不要求开局通读：
- controls.md：操作提示；observation.md：观测格式与分页。
- actions.md：高级输入、TAS 与计划；story.md：剧情、菜单及结算。
- workspace.md：观测文件、碰撞矩阵与查询；programs.md：程序优化。

笔记、公开反馈和程序额度遵循本次操作指南。本模式不挂载预设模拟器文件或速通知识库，也不联网查攻略；开放的有限预测只能经本次工具按额度使用。
