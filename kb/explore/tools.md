# 基本操作与工具

observe 获取当前画面和状态，不推进时间；act 执行按键并返回新画面和结果。
游戏在思考时冻结。失败可以重试。

需要计时时调用 `observe(detail="time")`：按秒返回桥接／章节计时、现实用时，以及各时长目标的已用／剩余时间；游戏帧取缓存，不推进游戏。桥接累计时钟不是本轮任务时长，任务限时看目标条件。

act 的 inputs 是按键段数组，每段写作 "帧数,按键"。游戏每秒 60 帧。
L/R/U/D 为方向，J 为跳跃，X 为冲刺，G 为抓墙，T 为交互；方向也可以用摇杆 A:角度（见 data.md）。不写按键代表松开所有键。
C 为确认，两种剧情模式都可用：画面冻结在等确认的界面（如第一次拿到磁带后的"B 面已解锁"、吃心后的诗句）时按它；auto 剧情模式下主控会先替你按，按了还卡住就由你处理。
agent 剧情模式还支持 B 返回、P 暂停、N 日志；菜单、重试、剧情与结算也由你发指令操作。
例如 ["10,R", "1,R,J", "12,R", "1"]：向右移动、向右起跳、继续移动、松开按键。
跳跃和冲刺按下时触发，想再次按下需先松开至少一帧。
一次推进多少帧由你决定；默认遇到死亡、换房间或通关会停下，也可以用 stop_on 在落地等时刻停下。
thought 写一句简短中文，说明这次准备尝试什么。看到结果后解释成败，再作下一次尝试。

narrate 更新观众看到的公开解说，不推进游戏；原生 GPT 执行器的公开 commentary 也会自动更新 HUD。
思考期间有判断就及时说明，不编造进展；直播时要更勤，节奏见系统提示词。
任务被工具故障、缺少能力等条件阻塞时，用 stop_run(reason="明确原因") 报告给用户：主控暂停试玩，章节内保持冻结，菜单正常运行，由用户决定继续还是停止；它不退出关卡，也不算通关。普通死亡或仍可尝试的难点不属于任务阻塞。

set_effort 可以申请调整下一轮推理强度；申请后简短结束本轮让其生效。
直播时，用户要求返回地图时调用 exit_level(reason="简短说明")，默认仅离开当前关卡，保留任务、后续章节和录制；需返回地图权限，不算通关，返回后先 observe 再自行选章。只有用户明确结束整次试玩时才设 finish_run=true，按允许的返回地图或保存退出操作收尾；不能用保存退出绕过返回地图权限。
不要因为遇到困难自行退出。

Read 读取 /kb 和 /workspace 的文件；Write 只写 /workspace。
Bash 在断网沙箱运行辅助程序，单次时长上限见系统提示词；实际工具名和前缀以执行器提供的映射为准。可以整理观测、保存笔记、绘图、写规划程序等。
（Codex 执行器的 Bash）若返回 stdout_truncated / stderr_truncated，输出只是首尾预览，不能当作完整几何或完整程序结果。用对应 stdout_path / stderr_path 读取完整输出；Read 可分页，超长单行用 Bash 筛选字段或分段读取。路径为空时检查保存错误，必要时重新运行并重定向到工作区文件。大量同类危险物宜与房间边界、出口、支撑和玩家状态分别输出，不要把整个明细列表当作短摘要。
/workspace/game/latest_obs.json 是最新观测，last_act.json 是上次动作的轨迹。
/workspace/game/show.py 提供 status("进度") 和 trajectory() 展示接口；有实际预测轨迹时可以展示。
规划回放保持开启；没有产生轨迹时不会生成虚假的回放。

载入、转场和重生由主控处理。剧情有 auto 与 agent 两种模式；agent 模式下主控在可尝试跳过时先交回，由你决定跳过或继续观看。
观测中的story提供当前画面已显示的对白、说话者头像标识、教学提示与纪念碑文字；结合返回截图理解内容，再决定是否推进或跳过，不能只盯等待标志翻页。它不是完整剧本，不包含未显示的后文。
截图为游戏画面层，不含对话等HUD层；当前对白与选项应读取story及dialogChoices，不能因截图里没有对白就当作没有剧情信息。
storyDecision=skip 表示剧情目前可尝试通过暂停菜单跳过（不保证存在跳过选项），不表示对白已显示完整。桥接 1.0.25 起支持此提前交接；旧版仍等实际输入节点。
cutscene(action="advance") 确认当前完整对白、明信片、旧纸的一页或 confirm 画面；choose(choice=index) 明确选择可见选项；skip 尝试跳过整段。watch 只播放桥接明确识别的动画，到下一输入节点或恢复控制即返回，每次工具调用最多自动等待600帧；超限且仍明确播放时可再次watch，未知状态立即交回，不重复空等。确认后的等待也遵守同一预算，不需要 wait。
storyInput 标明 dialogue / choice / tutorial / postcard / memo / confirm / breathing；confirm 表示照片、诗页或片尾等真实确认节点，可用 advance 或 C；教学使用 act，breathing 呼吸小游戏用 act 的 J、X 或 U 控制羽毛，松开使羽毛下落；旧纸可用 advance 或 C 翻页、U/D 翻页、B 关闭。storyPlaybackState 区分 playing / input / unknown / none；inCutscene 标记本身不证明动画正在播放，也不代表角色不能操作。桥接1.3.2起提供此事实，1.8.1补齐官图原生剧情及确认／小游戏边界，旧桥接缺字段时agent模式不猜测播放。
剧情中的教学或互动若需要方向、跳跃、冲刺等真实按键，仍可调用act；不能只等待或把教学输入当普通翻页。
遇到对话选项先读选项，再用 choose 或明确的 act 输入自行选择；advance 不会代选。
complete／completed=true 只表示游戏登记成绩；agent 模式须自行处理吃心提示、结算并返回稳定的 OuiChapterSelect 选章地图，主控才确认整章完成。之后若还有指定目标，你自行导航，主控不会代按或传送。
只完成本次指定章节；主控报告全部完成后结束，不能自行进入下一章。

纪念碑文字在 story 中标记为 memorial，随画面逐字显示；它不要求确认，也不会阻止移动。

主菜单、选档和选章地图在桥接连接期间仍正常运行；关卡、章节剧情及结算画面空闲时保持冻结，显式动作才推进。观测里的 frozen 表示是否冻结，不能用连接状态代替它。
