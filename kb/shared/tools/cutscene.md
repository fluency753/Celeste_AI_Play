# 剧情、菜单与结算（按需）

当前剧情模式和操作权限以主控配置为准。

载入和转场由主控处理。剧情有 auto 与 agent 两种模式。agent 模式下，死亡或房间重试后的重生先交回，可用 act 发送确认来缩短普通死亡动画，也可用 watch 有界等待。Token 推进接手重生时，observe 读取当前状态；其他情况下也可用 observe 有界等待。剧情可尝试跳过时同样先交回，由你决定跳过或继续观看。
观测中的story提供当前画面已显示的对白、说话者头像标识、教学提示与纪念碑文字；结合返回截图理解内容，再决定是否推进或跳过，不能只盯等待标志翻页。它不是完整剧本，不包含未显示的后文。
有原生剧情界面（对白、明信片等）可见时，截图范围为 story_hud：包含该界面并保持原尺寸，像素不对应世界坐标；否则截图只是游戏画面层。当前对白与选项仍以story及dialogChoices为准，不能因截图里没有对白就当作没有剧情信息。
storyDecision=skip 表示剧情目前可尝试通过暂停菜单跳过（不保证存在跳过选项），不表示对白已显示完整。桥接 1.0.25 起支持此提前交接；旧版仍等实际输入节点。
{tool:cutscene}(action="advance") 确认当前完整对白、明信片、旧纸的一页或 confirm 画面；choose(choice=index) 明确选择可见选项；skip 尝试跳过整段，成功后按原速有界等待角色恢复控制或出现下一输入节点。watch 等待已核实的入场、重生或桥接明确识别的演出，到下一输入节点或恢复控制即返回。演出使用单次调用预算，入场和重生按同一次过渡累计；未知状态立即交回。确认后的等待也遵守同一预算，不需要 wait。

交回时先看最新状态。已识别的输入节点按节点操作。主控可按正常速度等待已核实的入场，以及你选择等待的重生。同一次过渡按实际桥接帧累计，暂停和反复查询不会刷新预算。60 帧约 1 秒，不能凭单段未播完判断故障。有过渡依据且试玩运行中、没有待处理输入时，可以按反馈用 {tool:act} 显式提交短段空输入，设置停止事件和总推进上限。每段核对实际推进和状态变化，出现输入节点就处理；仍是同一冻结帧时，重复查询不算推进试验。watch 是已识别阶段的便利工具，不是通用等待；“没有待处理剧情”不能作为阻塞依据，已知刚重试/死亡但未识别时可按画面选择确认或有界空输入恢复。
storyInput 标明 dialogue / choice / tutorial / postcard / memo / confirm / breathing；confirm 表示照片、诗页或片尾等真实确认节点，可用 advance 或 C；教学使用 {tool:act}，breathing 呼吸小游戏用 {tool:act} 的 J、X 或 U 控制羽毛，松开使羽毛下落；旧纸可用 advance 或 C 翻页、U/D 翻页、B 关闭。storyPlaybackState 区分 playing / input / unknown / none；inCutscene 标记本身不证明动画正在播放，也不代表角色不能操作。桥接1.3.2起提供此事实，1.8.1补齐官图原生剧情及确认／小游戏边界，旧桥接缺字段时agent模式不猜测播放。
剧情中的教学或互动若需要方向、跳跃、冲刺等真实按键，仍可调用{tool:act}；不能只等待或把教学输入当普通翻页。
遇到对话选项先读选项，再用 choose 或明确的 {tool:act} 输入自行选择；advance 不会代选。

## 吃心提示与确认

agent 模式下，吃心后先用 {tool:observe} 核对 ui、story 和当前截图。Poem 可见不代表已能接受确认；需要推进演出时，用 {tool:act} 的短段空输入（只写帧数、不带按键）推进，再短按一次确认并用空输入松键，读取返回状态核验是否生效。默认 celeste_ai 格式的确认键是 C；celeste_tas 格式是 O，不能混用。帧数遵循当前工具限制，不猜固定等待时长。

确认未生效时，先松键并分段推进、复查，再按新的确认；不要一直按住确认，也不要仅反复观察代替推进。吃心演出不能假定由 watch 接管；冻结的提示或结算页仍需你显式推进和确认。确认后继续处理后续演出或结算，不因 completed=true 提前停下。

## 章节完成

complete／completed=true 只表示游戏登记成绩。agent 模式自行处理吃心提示与结算；主控在稳定选章地图核验，最后一整章也可在保存结束、身份匹配的稳定章节面板核验。若主控提示仍需回选章地图，短按 B 并核对菜单。之后若还有指定目标，你自行导航，主控不会代按或传送。
回到菜单后按主控反馈处理；未确认时先核对是否仍在过渡或有待处理的确认界面。
只完成本次指定章节；主控报告全部完成后结束，不能自行进入下一章。

纪念碑文字在 story 中标记为 memorial，随画面逐字显示；它不要求确认，也不会阻止移动。

迷你对白在 story 中标记为 mini_dialogue。整段显示完后一次性返回正文，可以继续移动，无需确认。

主菜单、选档和选章地图是否空闲冻结遵循当前配置，菜单切换期间继续推进；关卡、章节剧情及结算画面空闲时保持冻结，显式动作才推进。观测里的 frozen 表示是否冻结，不能用连接状态代替它。
