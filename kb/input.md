# 输入语义（游戏侧）

本文描述游戏如何把每帧的原始输入变成 Madeline 用到的量：`MoveX`、`MoveY`、瞄准方向、`Jump.Pressed` / `Jump.Check`、`GrabCheck`、冲刺/蹲冲按下等。物理如何使用这些量见 `player_physics.md`。

## 1. 每帧什么时候读输入

- 每个游戏帧最开始读取一次输入，并更新所有"虚拟按键"（缓冲计数器在这里递减或重置）。之后整帧的逻辑都看这一份结果。
- **冻结帧也会读输入**：冻结期间 Madeline 不更新，但按键缓冲照常递减、"刚按下"的边沿照常产生。所以冻结帧里按下的键，冻结结束后仍可能处于缓冲中。
- 本项目桥接工具的映射：
  - `L R U D`：手柄十字键（数字方向，分量恰为 ±1）。
  - `A:角度`：左摇杆满幅度，方向 (cos θ, sin θ)，0° 为右、90° 为上；出现时取代 `L R U D`。
  - `J` 跳、`X` 冲刺、`Z` 蹲冲、`G` 抓、`T` 交互：各对应一个手柄按键。
  - `K`、`Y`、`V`：第二个跳、冲刺、蹲冲键。同一个动作绑定了两个手柄按键（J 与 K 都是"跳"），游戏把它们当作同一个虚拟按键：任意一个"按住"就算按住，任意一个"刚按下"就算按下（2026-10-22 实测：按住 J 落地后不会再跳，此时按下 K 立即起跳）。
  - 抓取为**按住模式**，蹲冲为**按下模式**（见 §4、§6）。

## 2. 按键（VirtualButton）的三种读法

| 读法 | 含义 |
| --- | --- |
| `Check` | 当前帧按住 |
| `Pressed` | 本帧"算作按下"：本帧没有被"吞掉"，并且（缓冲计数器 > 0，或本帧刚从松开变为按住） |
| `Released` | 本帧刚从按住变为松开 |

每帧读输入时，按键按以下顺序更新：
1. 清除"本帧已吞掉"标记。
2. `缓冲计数器 −= dt`。
3. 若本帧刚按下（上一帧松开、本帧按住）：`缓冲计数器 = 缓冲时长`。
4. 若本帧**没有按住**：`缓冲计数器 = 0`（**松开即清空缓冲**）。

各按键的缓冲时长：

| 按键 | 缓冲时长 | 按住时算"按下"的帧数 |
| --- | --- | --- |
| 跳 Jump | 0.08 s | 按下帧 + 之后 4 帧 = **5 帧** |
| 冲刺 Dash | 0.08 s | 5 帧 |
| 蹲冲 CrouchDash | 0.08 s | 5 帧 |
| 交互 Talk | 0.08 s | 5 帧 |
| 抓 Grab | 0 | 只有按下那一帧 |

（帧数：0.08 → 0.0633 → 0.0467 → 0.03 → 0.0133 → −0.0033，前 5 个为正。计数在冻结帧里也递减。）

**吞掉按键**：
- "消耗缓冲"（ConsumeBuffer）：计数器清零。**注意：如果按键是本帧刚按下的，本帧剩余时间里 `Pressed` 仍为真**（边沿判断不受影响）；下一帧若仍按住，因为没有新边沿、缓冲也空了，`Pressed` 为假。
- "消耗按下"（ConsumePress）：计数器清零，且本帧剩余时间里 `Pressed` 为假。
- 所有起跳类动作（普通跳、蹬墙跳、爬墙跳、super、超级蹬墙跳）都会消耗跳键缓冲；开始冲刺会消耗冲刺键与蹲冲键的缓冲。

**由此得到的规则**：
- **要再按一次，必须先松开至少 1 帧**（需要新的"松开→按住"边沿）。按住不放只算一次按下。**例外：换用同一动作的另一个键**——按住 J 时按下 K，K 的"松开→按住"边沿就是一次新的按下，缓冲重新开始。所以相邻两帧连按跳：第 1 帧 J，第 2 帧 K（J 按不按都行）。冲刺 X/Y、蹲冲 Z/V 同理。
- **缓冲只在按住期间有效**：按下后若下一帧就松开，缓冲立即清零，只有按下那一帧算"按下"。想让一次按下在接下来几帧里"等待生效"，就要一直按住。
- 一次按下若当帧没被任何动作用掉，会在最多 5 帧内的第一个"可以执行"的时机生效：例如空中按跳、几帧后落地 → 落地后第一帧起跳；空中按跳、几帧后贴到墙 → 蹬墙跳；冲刺冷却中按冲刺 → 冷却结束那帧冲刺。

## 3. 跳键的两种用途

- `Jump.Pressed`：触发起跳（各状态里检查的时机见 `player_physics.md`）。
- `Jump.Check`（按住）：
  - 可变跳：`varJumpTimer > 0` 期间每帧检查，**一旦某帧没按住就永久取消本次可变跳**（即使之后再按住也不恢复）。
  - 半重力：每帧检查，|vy| < 40 且按住跳（或 AutoJump）时重力减半。

## 4. 抓（Grab，按住模式）

- `GrabCheck = Grab.Check`（当前是否按住），每帧检查。（游戏另有"切换模式"——每次按下翻转抓取状态——与"反转模式"，本项目固定为按住模式。）
- 进入攀爬需要该帧按住；攀爬中**任何一帧松开都会立即松手**。
- 贴墙下滑时：无水平输入但按住抓，也算"向墙方向"维持下滑；按住抓的贴墙下滑会让这面墙"被骑"（触发踩踏类机关）。
- 爬墙跳（而非蹬墙跳）的条件之一是按住抓且面朝墙。

## 5. 方向输入

### 5.1 MoveX、MoveY（整数轴，取值 −1 / 0 / 1）

| 轴 | 正方向 | 阈值 | 十字键 | 左摇杆 |
| --- | --- | --- | --- | --- |
| MoveX | 右 = +1 | 0.3 | 按下即 ±1 | x ≥ 0.3 → +1；x ≤ −0.3 → −1 |
| MoveY | **下 = +1**，上 = −1 | 0.7 | 按下即 ±1 | 摇杆 y ≥ 0.7（上）→ −1；y ≤ −0.7（下）→ +1 |

- 同时按住相反两个方向时"后按下者优先"：若之前是 +1，再加按反方向则变 −1；若两者同一帧从无到有，则为 0。
- MoveX 用于跑步、朝向、蹬墙判断、贴墙下滑；MoveY 用于下蹲（+1）、快速下落（+1）、攀爬上下、抓墙辅助（不得为 +1）。
- 蹬墙跳、翻墙、墙面弹簧之后的若干帧，Madeline 使用的 `moveX` 会被强制为固定值，真实输入被忽略（见 `player_physics.md` §3 第 14 步）。

### 5.2 瞄准向量 Aim（冲刺方向的原料）

- 由上下左右四个方向各自的强度合成：x = 右 − 左，y = 下 − 上（y 向下为正）。十字键给 ±1；左摇杆给原始分量（y 取反成"向下为正"）。
- 若合成向量长度 < 0.25，视为无方向输入。
- 相反方向同时按住时同样"后按下者优先"。
- 另有一个同样构造、阈值也是 0.25 的方向输入 Feather，只用于羽毛飞行与游泳（本三章不用）。

### 5.3 8 向吸附（GetAimVector）

每帧（`player_physics.md` §3 第 17 步）计算一次 `lastAim`：
1. 若 Aim 为零向量：`lastAim = (Facing, 0)`（朝向的水平方向）。
2. 否则取角度 `a = atan2(y, x)`（屏幕坐标，向上为负角度）。容差 `tol = 22.5°`；**若 a < 0（指向上半平面）则 tol = 17.5°**。
3. 依次判断：与 0°（右）的夹角 < tol → (1, 0)；与 180°（左）< tol → (−1, 0)；与 −90°（上）< tol → (0, −1)；与 90°（下）< tol → (0, 1)。
4. 都不满足：`lastAim = (sign(x), sign(y))` 归一化，即 (±0.70710677, ±0.70710677)。

效果：偏上方向时，上方对角线的范围更宽（55°），上、左、右的偏上一侧更窄；下半平面各方向均为 45°。

**`A:角度` 对应的冲刺方向**（角度按桥接约定：0° 右、90° 上，逆时针）：

| 输入角度范围 | lastAim |
| --- | --- |
| [0°, 17.5°) 及 (337.5°, 360°) | 右 |
| [17.5°, 72.5°] | 右上 |
| (72.5°, 107.5°) | 上 |
| [107.5°, 162.5°] | 左上 |
| (162.5°, 202.5°) | 左 |
| [202.5°, 247.5°] | 左下 |
| (247.5°, 292.5°) | 下 |
| [292.5°, 337.5°] | 右下 |

（恰在边界上时浮点误差可能让结果落到任一侧，未核实；规划时避开边界 ±1°。）

**同一 `A:角度` 下的 MoveX / MoveY**（满幅度摇杆）：

| 角度（相对水平/竖直） | MoveX | MoveY |
| --- | --- | --- |
| 离水平方向 ≤ 72.5°（即 \|cos\| ≥ 0.3） | ±1 | — |
| 离竖直方向 ≤ 45.5°（即 \|sin\| ≥ 0.7） | — | ±1 |
| 例：45°（右上） | +1 | −1（上） |
| 例：30° | +1 | 0 |
| 例：80° | 0 | −1 |

十字键对角（如同时按 R 和 U）则 MoveX = +1、MoveY = −1、瞄准为右上，三者一致。

### 5.4 朝向 Facing

- 每帧若 `moveX ≠ 0`（且可控、不在攀爬等少数状态），`Facing = moveX`。冲刺中也会随输入改变。
- 无方向输入时冲刺朝 Facing 水平方向；super / hyper 的水平方向也取 Facing（在起跳那一帧按反方向即可反向）。

## 6. 冲刺与蹲冲（按下模式）

- 冲刺键 `X`：`DashPressed = Dash.Pressed`。
- 蹲冲键 `Z`：`CrouchDashPressed = CrouchDash.Pressed`。按下模式下它是一个独立按键，不需要同时按冲刺键。
- 能否冲刺：任一为"按下"，且冷却已过、还有冲刺次数（详见 `player_physics.md` §8.1）。
- 用蹲冲键开始的冲刺：若开始时不在下蹲，就进入下蹲（8×6 碰撞箱）冲刺；与"开始冲刺那一帧按住下"效果相同。例外：若人在空中且已经下蹲，任何冲刺都会先起身。
- 下蹲中的冲刺在冲刺状态内起跳即为 hyper（vx = 325 × Facing，vy = −52.5）。

## 7. 交互键（Talk）

- 用于告示、望远镜、NPC 等。若此刻站在可交互对象的范围内并且交互键为"按下"，本帧的起跳与冲刺不会发生。

## 8. "哪一帧的输入决定什么"速查

| 行为 | 读取哪一帧的什么输入 |
| --- | --- |
| 跑步加速、朝向 | 每帧的 MoveX（被强制期间除外） |
| 普通起跳 | 跳键"按下"（含缓冲）的帧中第一个满足起跳条件的帧，起跳**当帧**生效 |
| 可变跳高度 | 起跳后每帧是否按住跳；某帧松开即永久截断 |
| 冲刺开始 | 冲刺/蹲冲键"按下"的帧中第一个满足条件的帧（F0） |
| 冲刺方向 | **冻结结束后第一帧（F4）** 的瞄准输入；F0–F3 的方向不影响方向 |
| 冲刺是否下蹲 | F0 的 MoveY 或是否用蹲冲键 |
| super / hyper | F4–F14 中某帧跳键"按下"且在地面/土狼时间内；水平方向取该帧的 Facing |
| 冲刺前误按跳 | 若跳键在 F0–F4 期间处于"按下"（含缓冲），F4 会直接触发 super 或蹬墙跳（见 `player_physics.md` §8.6） |
| 抓墙、攀爬、松手 | 每帧的 GrabCheck |
| 攀爬上下 | 每帧的 MoveY |
| 爬墙跳转蹬墙 | 爬墙跳后，**上一帧**的 MoveX 远离墙（1 帧延迟） |
| 快速下落 | 每帧 MoveY = +1 |
| 贴墙下滑 | 每帧 MoveX 指向墙（或无水平输入但按住抓），且 MoveY ≠ +1 |
| 梦境冲刺结束时 | 结束那帧：跳键"按下"→梦境跳；按住抓 + MoveX 指向墙 → 直接抓墙 |

## 9. 两个时间线示例

**落地前缓冲起跳**：第 k 帧在空中按下跳并一直按住；第 k+2 帧移动中落地；第 k+3 帧开始时 onGround 为真，跳键仍在缓冲内（k、k+1、k+2、k+3、k+4 为"按下"），于是第 k+3 帧起跳。若第 k+1 帧就松开了跳，缓冲被清空，第 k+3 帧不会起跳。

**普通地面冲刺**：F0 按下 X（同时方向键不重要）；F1–F3 冻结；F4 按住 R+U → 冲刺方向右上；F4–F13 以 (169.7, −169.7) 移动；F14 结束速度 (113.1, −84.9)。若 F0 时同时按着 J 不放，F4 会变成 super 而不是右上冲刺。
