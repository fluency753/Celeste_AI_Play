# HUD 工具调用记录

桌面 HUD 的历史区可切换“对话 / 工具记录”。工具记录显示本次运行最近的调用，点击展开请求参数和简短返回摘要，不另开窗口、不挤占对话历史。OBS 页面不显示工具入口，也不请求 `/hud/tools`。

需要导出整个会话跨运行的公开文本、时间与模拟器额度时，使用[会话导出工具](SESSION_EXPORT.md)。

## 能看到什么

- 完整房间布局、区域碰撞精查和完整玩家状态分别标记；区域坐标、分页等实际参数可展开查看。
- 文件读取显示路径与行范围；Bash 显示经过长度限制和敏感值遮盖的命令、agent 填写的说明，不声称知道程序内部访问过哪些文件。
- 动作显示请求输入、计划帧数；模拟显示候选条数；剧情、推理强度、阻塞与退出操作也会记录。请求不等于实际执行、读取完整或理解正确。
- 状态区分执行中、已返回、明确失败、结果未确认、轮次已结束但未收到结果。计时结束不视作成功。
- 返回摘要只保留可核实的文字字符数、结构化对象数等。原生工具文字不等于最终模型上下文；图像附件单独按调用 ID 关联，无法确认数量时显示未知，不将工具结果中的零图片数当作模型没有收到图片。

## 来源与范围

后台只读当前运行目录的日志，不连接游戏桥接。Codex 从 `codex_events.jsonl` 读取动态工具、原生 Shell、文件编辑和看图事件，执行器在真实请求与返回边界追加 `tool/history` 安全摘要；`decision_timing.jsonl` 补充开始时间和耗时，不据此判定成功。保留宿主机旧版原生日志兼容：校验会话身份、文件实际路径及初始工作目录，只为本次计时登记的调用补缺字段。新版事实优先，复用会话的其他运行不会混入。Claude 从本运行的 `agent_events.jsonl` 获取相同事实。

同轮附件读取 `tool_deliveries.jsonl`，区分待投递、已排队、已确认接收和接收未确认；排队不是接收证明。回执重放不重复计数。更新前未保存的动态工具参数和结果摘要无法还原，继续显示未知。

参数不完整或来源无法校验时明确提示，不根据解说猜测。不会显示结果正文、图片编码、写入内容或内部推理。日志缺失、超长行、暂时占用和载入中的详情不伪装成完整记录。

工具记录按需增量读取；每批读取和单行各限 4 MiB，最多保留 240 条展示数据，接口返回最近 50 条，调用 ID 与附件去重缓存各限 4096 项。首次打开可能显示“正在载入历史详情”。截断或无效行数量会提示，旧记录不作无限归档查询。

## 验证

`python tools/run_tests.py calibration.tool_history_test calibration.hud_history_test calibration.mod_hud_test` 验证来源隔离、真实 HTTP 消费、状态、遮盖、半行、超长行、重放与迟到事件。

安装 Playwright 及可用浏览器后，在仓库根目录运行 `node calibration/tool_history_ui_check.cjs`。Windows 可设置 `PLAYWRIGHT_CHANNEL=msedge` 使用已安装的 Edge。检查使用隔离页面与假接口，不操作游戏：覆盖初始空模型与控制接口慢响应后顶部时间、上下文正常更新，以及验证切换、展开保留、命令文本转义、跨运行拒绝，以及 OBS 工具请求为零；截图写入 `local/tool-history-preview.png`。
