# 使用指南

这份指南写给第一次使用的人：需要准备什么、怎样部署、怎样开第一次运行、运行中怎么看和怎么介入、录像在哪里，以及常见问题。命令和参数的完整细节见 [DEPLOY.md](DEPLOY.md)（部署）和 [USAGE.md](USAGE.md)（详细使用说明）。

> 项目仍在开发中，流程和默认值会随版本调整。遇到与本文不一致的地方，以仓库里的代码和最新文档为准。

## 0. 推荐：让 AI 助手帮你操作

部署这套系统要装好几样软件、跑不少命令。**推荐让一个 AI 编程助手来当"执行器"**：它负责阅读文档、部署、启动、运行中的介入与监督。任何能在你电脑上读文件和执行命令的 AI 都可以，例如 Claude Code、Codex。

怎么做：

1. 在你的电脑上装好这个 AI 助手，让它在本仓库的目录里工作（还没下载仓库时，可以让它先 `git clone https://github.com/fluency753/Celeste_AI_Play.git`）。
2. 对它说：

   > 请阅读本仓库的 docs/AI_GUIDE.md，按它帮我部署并启动一次试玩。

3. 它会按 [AI_GUIDE.md](AI_GUIDE.md) 一步步检查环境、部署、在测试存档上试玩，遇到需要你决定或你亲手做的事时停下来问你。

**下面这些必须你自己做**，AI 助手会在需要时提醒你：

| 事项 | 为什么 |
| --- | --- |
| 购买并安装正版《蔚蓝》，用 Olympus 装好 Everest | 涉及购买与你的账号 |
| 以管理员身份安装 WSL2 并重启电脑、首次打开 Docker Desktop 接受协议 | 需要管理员权限与重启 |
| 登录订阅或填写密钥：在浏览器里授权 `claude setup-token`，或提供第三方平台的 API 密钥，或完成 Codex 的设备登录 | 账号凭据只能由你授权，AI 助手不应看到或保存明文 |
| 在游戏里建一个测试用的存档（也可以让主控新建） | 决定 AI 能碰哪个存档 |
| 建一个只启用 CelesteAIBridge 的 Mod 配置；在 Steam 里关闭《蔚蓝》的云同步 | 在 Mod 管理器和 Steam 里操作 |
| 批准每一次正式运行，以及任何删除文件、容器或数据卷的操作 | 正式运行会占用游戏、录像并消耗额度 |

不想用 AI 助手也完全可以，按下面的步骤自己做。

## 1. 需要准备什么

| 项目 | 要求 | 必需？ |
| --- | --- | --- |
| 系统 | Windows 10 2004（build 19041）或更新，或 Windows 11 | 是 |
| 游戏 | 正版《蔚蓝》（Steam 版 1.4.0.0） | 是 |
| Mod 加载器 | Everest（.NET 8 版本），用 [Olympus](https://everestapi.github.io/) 安装，装完至少启动一次游戏 | 是 |
| Python | 3.11 或更新（部署脚本找不到时会提议用 winget 安装 3.13） | 是 |
| .NET 8 SDK | 编译桥接 Mod 用（部署向导可以用 winget 安装） | 是 |
| WSL2 + Docker Desktop | 智能体在 Docker 容器里运行 | 是 |
| OBS Studio + ffmpeg | 录像用（部署向导可以用 winget 安装） | 录像时 |
| 模型账号 | 下面三选一：Claude 订阅（Pro/Max）；提供 Anthropic 兼容接口的平台的 API 密钥（如 DeepSeek）；能使用 Codex 的 ChatGPT 账号（接入 GPT） | 是 |
| 硬件 | 内存 16 GB 起（建议 32 GB），磁盘 20 GB 可用起；有 NVIDIA 显卡时录像用硬件编码 | — |

另外两点：

- **仓库路径只能用英文**（OBS 插件用 ANSI 接口写录像文件）。
- 速通模式的"预置模拟器"和探索模式的"限额短路线预测"需要一个由游戏代码生成的标准模拟器（`sim\dist`），它**不随仓库分发**。没有它也能玩：探索模式照常，速通模式运行"关模拟器"的版本。

## 2. 一步步部署

1. **备份游戏目录**（以防万一）。
2. **装好 Everest**：用 Olympus 给《蔚蓝》装最新稳定版 Everest，启动一次游戏，游戏目录里出现 `Celeste.dll` 即成功。
3. **准备 Mod 配置**：在 Olympus 或 CeleMod 里建一个**只启用 CelesteAIBridge** 的配置（例如叫 AIPlay），AI 游玩时用它。其他 Mod 可能改变手感或抢占按键。
4. **游戏设置**：窗口化或无边框，1920×1080；辅助模式与变体关闭。在 Steam 里**关闭《蔚蓝》的云同步**。
5. **装 WSL2**（只需一次）：右键开始按钮 →"终端（管理员）"，执行 `wsl --install --no-distribution`，然后重启电脑。
6. **获取仓库**：

   ```powershell
   git clone https://github.com/fluency753/Celeste_AI_Play.git
   cd Celeste_AI_Play
   ```

7. **运行一键部署**：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\setup.ps1
   ```

   它先准备 Python 虚拟环境 `.venv`，再启动部署向导。向导一共 12 步，每一步先检查，已就绪的可以跳过，要安装或改动什么都会先问你：

   | 步骤 | 向导做什么 | 你要做什么 |
   | --- | --- | --- |
   | system | 检查 Windows、Python、winget、git | — |
   | game | 找到游戏目录，检查 Everest | 确认游戏目录 |
   | dotnet | 找 .NET 8 SDK，没有就安装 | — |
   | bridge | 编译并安装桥接 Mod 与常驻核心（原文件先备份） | **先关掉游戏** |
   | docker | 检查 Docker，构建智能体镜像（约 1～2 分钟） | 没装 Docker Desktop 时按提示安装，打开它等到 Engine running |
   | platform | 选模型平台，配置令牌或密钥，填模型名 | Anthropic：浏览器里授权，把令牌粘贴回来；其他平台：给密钥文件或粘贴密钥 |
   | recording | 找 OBS 与 ffmpeg，编译安装锁步插件 | 选要不要录像；**编译插件前关掉 OBS** |
   | sim | 检查预置模拟器 | 有的话给出位置，没有就跳过 |
   | kb | 生成知识库参考资料（可选，要能访问 celeste.ink） | 选要不要生成 |
   | saves | 读出游戏里的存档名 | 填调试用存档和正式用存档的名字 |
   | switches | 生成本机启动脚本 `start_local.ps1` | 选标签、章节、各个开关 |
   | checks | 自检：容器隔离验收、冒烟测试等 | 选要跑哪些（有几项要先开游戏） |

   向导的回答存在 `configs\local.deploy.json`，下次运行时作为默认值。中途按 Ctrl+C 也会保存已填的部分。只想重做某几步时：`setup.ps1 -Only platform,switches`。
8. **检查一遍**：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\setup.ps1 -Check
   ```

   它只检查、不改动。每一项显示"就绪"或"缺少"。

向导的 platform 步骤只配 Claude Code 执行器用的平台。要用 Codex 执行器（GPT）时，另外执行一次 `.\.venv\Scripts\python.exe -m orchestrator.codex_container --account login`，按提示在浏览器里完成授权。

## 3. 用控制台开第一次运行

1. **开 Docker Desktop**，等左下角显示 Engine running。
2. **开游戏**（用只启用 CelesteAIBridge 的 Mod 配置），停在标题画面或任意菜单即可。主控会自己用菜单进入存档。
3. **打开控制台**：双击仓库根目录的 `CelesteAIConsole.exe`。也可以运行 `.\.venv\Scripts\python.exe -m overlay.console`。
4. **在"存档与章节"页**：
   - 填一次游戏位置（控制台会记住；空着时自动查找）；
   - 选存档：**选你的测试存档**，或选"新建"让主控新建一个；
   - 选章节：第一次建议只玩序章。可以选官方章节的 A/B/C 面。
5. **在"运行"页**：
   - 选执行器与提供方、模型、推理强度；
   - 填智能体标签（例如 `dev-trial`；它决定日志目录 `runs\<标签>\` 和智能体的工作区）；
   - 现实时间上限默认 1000 分钟，第一次试玩可以改小，例如 30；
   - 游玩模式默认"探索"，第一次建议保持；
   - 想先确认流程时，可以关掉"OBS 录屏"。
6. 点**开始运行**。页面底部显示等价的命令行。

开始后主控依次：检查桥接版本 →（录屏时）启动 OBS → 用菜单进入存档与章节 → 核对存档名并备份存档 → 启动智能体容器。智能体先读完知识库（准备阶段，不计时），然后开始游玩。

控制台启动的运行在独立的后台进程里进行，关掉控制台窗口不影响它。

## 4. 怎么看

- **游戏画面右上角的 HUD**：章节计时、推理强度、思考与工具用时、死亡次数、正在调用的工具，以及智能体写给观众的思考语句。
- **控制台"运行"页**：中间"当前运行"显示状态、章节与房间、计时、死亡、决策数、上下文；右边"对话"显示智能体的解说和回复。
- **顶栏三盏灯**：游戏、OBS、主控各自的状态。
- **命令行**：`.\.venv\Scripts\python.exe tools\run_status.py` 显示最近一次运行的统计和最近的决策（加 `-n 30` 显示更多）。

游戏大部分时间"不动"是正常的：智能体在思考或运行程序时，游戏冻结在当前帧。

## 5. 暂停、中断、续跑

都在控制台"运行"页的"当前运行"里操作：

| 操作 | 效果 |
| --- | --- |
| **暂停 / 继续** | 正在执行的动作走完后暂停，游戏保持冻结；点继续接着玩 |
| **发消息** | 在右边"对话"框输入，Enter 发送。Claude Code 执行器先停下当前这一轮（正在执行的动作照常走完），再把消息交给智能体；Codex 执行器把消息插入当前这一轮 |
| **停止并保存录像** | 结束运行、收尾录像、交还游戏控制，游戏恢复正常 |
| **中断（保持冻结，可续跑）** | 结束主控，但游戏保持冻结在当前帧、章节计时不走，录像会话也保留 |

中断之后：

- 在"运行记录"里点那次运行的**续跑**，接着原来的章节、统计、会话和同一份录像。
- 不打算续跑时，点**交还游戏控制**：先收尾录像，再让游戏恢复正常。
- 中断后**不要关游戏**：章节进度只在游戏内存里，游戏关掉就不能续跑了。也尽量不要关 OBS。

## 6. 录像在哪里

每次运行的产出在 `runs\<标签>\<时间戳>\`，录像在其中的 `recording\`：

- 默认每章一个视频，在 `recording\chapter-001\`、`chapter-002\`……里；
- `gameplay.mp4` 是完整版（含规划回放）；
- `gameplay_pure.mp4` 是纯享版（只有真实游玩的帧）。

同一目录下还有 `summary.json`（成绩与结束原因）、`metrics.json`（统计）、`decisions.jsonl`（每次动作）、`save_backup\`（开跑前的存档备份）等。控制台"运行记录"里每次运行都标了有没有录像。

## 7. 常见问题（Q&A）

**Q：需要什么订阅或密钥？能不能用 DeepSeek 等其他模型？**
A：三选一。Claude 订阅（Pro/Max）：用 `claude setup-token` 生成令牌，不需要 API 密钥。提供 Anthropic 兼容接口的平台（如 DeepSeek）：可在控制台的自定义提供方里填写接口地址与密钥（或编辑 `configs/local.providers.json`），已有的平台预设在 `configs/providers.json`。GPT：走 Codex 执行器，用 ChatGPT 账号设备登录。

**Q：一次运行要多久？会不会花很多额度？**
A：取决于模型、章节和设置，差别很大。智能体每次都要先思考再操作，现实用时远长于录像长度。主控有一个现实时间上限（默认 1000 分钟，不含准备阶段与等待额度的时间），第一次试玩建议设小一点，例如 30 分钟。

**Q：现实时间上限到了会怎样？**
A：主控停止运行。Claude Code 执行器停下时游戏冻结在当前帧、章节计时不走，可以续跑（续跑时可以加大上限）；Codex 执行器到上限时正常结束并交还游戏控制。这个上限不显示给智能体。

**Q：额度用完了会怎样？断网了会怎样？**
A：Claude 订阅额度用完时，游戏保持冻结，主控等额度重置后接着同一个会话玩，等待时间不计入现实用时；要等超过 24 小时就停止（之后可以续跑）。模型连不上时同样冻结等待，网络恢复后自动接着玩，连续超过 24 小时连不上才停止。第三方平台余额不足时主控会停止，处理好后续跑。

**Q：智能体会不会动我自己的存档？**
A：主控只进入你指定的存档，存档名不一致时拒绝开始，开跑前还会把这个存档备份到运行目录的 `save_backup\`。调试和试玩请用一个单独的测试存档，不要指定你自己正在玩的存档。存档进度出问题时，关掉游戏后从 `save_backup\` 恢复。

**Q：游戏为什么看起来卡住了、不动？**
A：这是正常的：智能体思考或运行程序时，游戏逐帧冻结，等它想好了才推进。看 HUD 或控制台的状态（例如"思考中""运行工具""执行中"）就知道它在做什么。状态长时间没变化时，看控制台"对话"里的消息，或运行 `tools\run_status.py`。

**Q：怎么暂停、中断、续跑？"中断后游戏保持冻结"是什么意思？**
A：在控制台"当前运行"里点暂停、继续、中断；续跑在"运行记录"里点。保持冻结是说游戏停在中断那一帧、章节计时不走，下次续跑从同一帧接着玩，录像也接在同一份里。不续跑时点"交还游戏控制"。

**Q：录像在哪？完整版和纯享版有什么区别？**
A：在 `runs\<标签>\<时间戳>\recording\` 里（默认每章一个子目录）。完整版 `gameplay.mp4` 含规划回放，纯享版 `gameplay_pure.mp4` 只有真实游玩的帧。两个版本都不含思考时间。

**Q：为什么录像里没有规划回放？**
A：规划回放默认关闭，要打开控制台的"规划回放"开关（命令行 `--playback`）。打开后，也只有智能体把自己算出的逐帧轨迹交给工作区的绘制接口 `show.trajectory()` 时才有内容，所以通常要在提示词里要求它主动写推演程序并适配这个接口。速通模式开了预置模拟器时，模拟器的推演也会画出来。

**Q：速通模式和探索模式选哪个？速通为什么写着"需自配标准模拟器"？**
A：第一次建议用探索模式（控制台的默认）：智能体像新手一样边试边学，不需要模拟器。速通模式以最短的章节计时为目标，读完整知识库；它最适合配合预置模拟器逐帧推演路线，而模拟器由游戏代码生成、不随仓库分发，要自己准备。没有模拟器时速通模式运行关模拟器的版本，智能体只能用自己的办法。

**Q：能不能玩 B 面、C 面？能不能玩 MOD 地图？**
A：可以选官方章节的 A/B/C 面。MOD 地图在未来版本中支持，目前只支持官方章节。

**Q：能不能在运行中给智能体发消息？会不会打断它？**
A：可以，在控制台"对话"框里发。Claude Code 执行器会先停下当前这一轮再把消息交给它，正在执行的动作照常走完；Codex 执行器把消息插入当前这一轮。暂停时智能体只回复，不操作游戏。

**Q：控制台打不开怎么办？**
A：双击 `CelesteAIConsole.exe` 提示没有 `.venv` 时，先运行一键部署 `setup.ps1`。也可以在仓库目录运行 `.\.venv\Scripts\python.exe -m overlay.console --browser`，用浏览器打开 `http://127.0.0.1:47790/console`。提示端口上是旧版 HUD 服务时，在没有运行的情况下加 `--restart-service`。

**Q：主控提示"已有主控在运行"？**
A：同一时间只能有一次运行。先在控制台停止或中断正在进行的运行，等它退出再开新的。后台主控的输出在 `local\background\<启动时间>\output.log`，状态在同目录的 `status.json`。

**Q：游戏没加载桥接 Mod？**
A：看游戏目录的 `log.txt` 里有没有 `[CelesteAIBridge] loaded`。没有时，确认 Mod 配置里启用了 CelesteAIBridge；还不行就关掉游戏，重新运行 `setup.ps1 -Only bridge`。主控提示桥接版本太旧时也这样更新。

**Q：OBS 没录上？**
A：先运行 `.\.venv\Scripts\python.exe tools\obs_setup.py status` 看锁步插件是否加载；没加载就关掉 OBS，运行 `setup.ps1 -Only recording` 重新安装插件。OBS 弹出"安全模式"时选正常模式（安全模式不加载插件）。录制时游戏窗口不能最小化。

**Q：提示找不到 docker，或 Docker 没启动？**
A：从开始菜单打开 Docker Desktop，等左下角显示 Engine running，再新开一个 PowerShell 重试。刚装好 Docker 时，已经打开的终端里可能找不到 `docker` 命令。

**Q：想让智能体从零开始（清掉它写的程序和笔记）？**
A：删除 `workspaces\<标签>\`；会话记录在 Docker 数据卷里，先 `docker rm -f celeste-agent-<标签>`，再 `docker volume rm celeste-claude-<标签>`。探索模式的工作区和容器名另加 `-explore` 后缀。删除前确认标签没写错。

**Q：怎么更新到新版本？**
A：控制台"关于"页可以检查更新，没有运行、本机没改动仓库文件时可以一键更新。桥接 Mod、Python 依赖或容器镜像有变化时，页面会提示另外处理，做法见 [DEPLOY.md 第 10 节](DEPLOY.md#10-更新迁移与卸载)。

更多问题见 [DEPLOY.md 第 11 节](DEPLOY.md#11-常见问题) 与 [USAGE.md 第 7 节](USAGE.md#7-常见问题)。
