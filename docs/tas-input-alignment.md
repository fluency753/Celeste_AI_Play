# TAS 输入对齐约定

agent 可显式使用 `input_format="celeste_tas"` 执行离散按键，或在 JSON 计划中声明此字段（桥接 1.0.20 起）。省略时仍为 `celeste_ai`。已实现 TAS 双键、共享菜单绑定、来源游标及截断后缀，不代表支持完整 TAS 脚本语言。

支持按键 `L R U D J K X C Z V G H S Q N O`。摇杆 `F`、独立方向通道 `A/M`、自定义键 `P` 及 `Read`、`Set`、`console` 等命令明确拒绝，不静默忽略或自动执行。

## 使用

工作区提供 `/workspace/game/tas.py`。1A输入文件第1行为装载命令，第2行起为输入；核对当前初态后，可显式生成一个窗口：

```sh
python /workspace/game/tas.py /workspace/reference/1A.tas --start-line 2 --offset 0 --count 600 --out /workspace/plan.json
```

由 agent 调用 `act(plan_file="/workspace/plan.json", thought="...")` 执行。返回 `input_cursor.next`、`next_location` 和 `remaining_inputs`；下一窗口使用实际消耗后的游标，不按请求帧数盲目前移。记录保存在 `game/last_act.json` 与决策日志中。
游标是选定文档内从0开始的输入帧偏移，重建时使用相同来源范围。剩余数组也须放在声明celeste_tas的JSON中，不能交给默认格式的旧工具。跳过装载命令不会替你建立相同初态；源输入帧总数与文件声明的章节计时帧数也不必相同。

程序中可 `load(path,start_line=...)`、`window(document,offset,count)`。`to_sim(inputs)` 将支持的 TAS 游戏按键转换给现有 `Sim.run`／`SimPool.run_many`；限额 `simulate` 也接受显式格式。模拟仅支持 `L R U D J K X C Z V G`，菜单、重试、第二抓键及其尚未释放的快照明确拒绝，不扣除失败转换的额度。模拟结果输出计划仍为本项目格式，不冒充原 TAS 来源。

TAS执行及observe不自动播放剧情或转场，需要 agent 明确输入。切换格式前先用原格式推进一帧空输入松键；不隐式插帧。菜单仍按项目约定自由运行，因此不以菜单空闲的现实时间证明TAS逐帧等价。

## 显式选择格式

现有 `act` 按键含义保持不变。不按文件后缀猜测，也不在相同输入文本上自动切换解释。格式标识随计划、调用、观测、工作区数据和决策日志保存；恢复时从桥接观测核对当前格式。

`act`、计划文件与模拟转换使用同一离散按键规范；不支持的动作、命令或版本差异明确返回。原始 TAS 行号、输入段、帧偏移及源文件哈希一并保留，便于定位差异。

## 对齐动作与绑定，不只替换字母

当前参考实现中，TAS 的 `J/K` 为两套跳键，`X/C` 为两套冲刺，`Z/V` 为两套蹲冲，`S` 为暂停，`O` 为确认；本项目第二冲刺为 `Y`，`C/B/P/N` 为独立菜单输入。具体含义仍须根据来源版本验证。

TAS 的游戏按键可能同时绑定菜单或交互功能，例如跳跃兼确认、冲刺兼取消。转换须保留同一帧实际产生的绑定信号，不能仅按当前场景选择其中一个功能；跨场景切换也必须成立。合并两个现有动作是否等价，要用原生输入更新验证，不能仅凭名称认定。

两套键保持各自按下边沿：交替按键、同帧双键、持续按住与松开分别处理。同帧双键不等于游戏执行两次动作。摇杆角度、幅度、死区与方向组合也属于输入语义，不擅自量化或补键。

## 保留逐帧时序

- 输入段连续执行时不自动插入松键；分批调用、观察与规划回放不应制造额外输入边沿。
- 动作因换房、死亡或输入节点截断后，以实际消耗帧数保存游标及未执行后缀，不能丢帧或重复输入。
- 明确游戏更新、加载、冻结帧、模拟器采样和章节计时的口径。对照基线时记录实际起点和计时边界。
- `Read`、重复段等展开保留来源和游标；`ChapterTime` 等成绩元数据不当作按键。
- `console`、`Set` 等配置或装载命令不是普通按键。需单独核验能力和授权，由 agent 显式请求，主控不借导入自动改设置、选关或传送。

## 验收方向

先比较原生虚拟输入信号，再比较同初态游戏轨迹。覆盖双键交替与同时按下、跨调用持续按键、菜单兼用绑定、场景切换、提前截断后续接、模拟与实机的一致性。存在差异时记录首个分歧帧、来源行、输入状态和游戏状态；不能只比较最终用时。

本次 1A 学习仍使用已保存的原输入基线，先核对来源和初态，再显式选择TAS格式；轻量搜索候选只用于分析，不实际采用。不能把输入解释或初态差异当成超越 TAS 的证据。
