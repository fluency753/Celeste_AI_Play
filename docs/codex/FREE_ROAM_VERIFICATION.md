# 已到访地图自由探索验收

2026-10-29，Bridge 1.10.0；Runtime 未修改、未部署，未连接用户游戏／OBS 或恢复原试玩。

## 行为与边界

地图范围（单章／顺序／已到访集合）、完成策略和动态停止目标独立。已到访集合按槽位绑定并区分 SID 与面别，首次在实际载入前从候选存档的原生正向记录推断后持久化，续跑不因解锁或完成而扩大。未知候选先发空许可，不能先自动进入新章再将其算作历史到访。默认实验权限只开放返回地图和重启，保存退出仍独立配置。地图和检查点导航由 agent 操作。

存档没有通用的精确到访标记；历史零计时零记录的进入无法追溯，第三方 Mod 对完成统计的修改也会影响推断。空集合不代表无限制。

审查发现并修正了首次 connect 早于 run_state 创建、动态剧情切换绕过初始化限制、选档恢复绕过章节面板、重复通关统计被误当作恢复计划进度，以及继续策略下动态部分计划和停止文案不一致等入口。启动宏最初的测试替换了内部宏，掩盖了错误公开参数；已改用真实 `load_save_and_freeze`，回归保留真实 BridgeClient、菜单宏和菜单消费者，仅替换 socket/file IO。恢复的完成记录与尚待结算分开保留，计时目标不因反复进入重置。

## 自动化与原生检查

- Python 回归保留真实配置解析、启动、许可持久化、导航、目标及控制消息消费者；外部进程、桥接和时间源隔离。新增 `free_roam_test.py`、`free_roam_entrypoints_test.py`，并扩充控制、重载及会话入口回归。
- 原生 `calibration/chapter_reset` 调用真实游戏菜单和 StepJob，覆盖同 SID 不同面、复合输入、跨 SID 检查点、错误槽位、空集合、畸形协议、存档统计来源，以及选档／首次入场／最终入场入口。日志：`local/free-roam-native.log`。

## 实际执行器接收与自主试玩

真实 `gpt-6.1-terra` 经 `CodexRunner._request → build_server → GameSession`，外部游戏使用隔离菜单状态机。拒绝身份与原因原样来自原生检查的 `test/target` A／B 面结果；计划帧数按模型实际提交的输入生成，不冒充官方地图或真实游戏画面试玩。

模型实际收到 B 面拒绝、许可 A 面、已执行 0/1 帧及后续输入未执行的说明，自主返回并选择 `early` 检查点；通关结算回地图后没有停止，而是再次入场实验。独立时长目标累计 8 个实际 fixture 输入帧后触发，时间查询及下一轮观察均被拒绝，模型据实际结果结束。两次入场、一次通关，所有 `consumed <= planned`。

最终证据：`local/free-roam-receiver-20261029-112612/result.json`。较早的 `112210` 轮存在验收 fixture 跳钟问题，已废弃并修正重跑，不作为计量证据。本轮未验证真实用户存档、OBS 成片或任意 Mod 的所有特殊入场路径。
