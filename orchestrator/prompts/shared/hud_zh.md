# 公开解说与工具状态（HUD）

HUD 显示{hud_thought_shown}，以及正在运行的工具和它的进度；屏幕前和录像里的观众都看得到。

- **用一句话更新路线进展**：观察后有了初步路线判断，或之后有明显进展时，调用 `{tool:narrate}`。说清当前难点、路线取舍或下一步验证事项{narrate_viewers}只写适合公开展示的简短结论，不写内部推理过程、具体数值或算法；技巧与机制的专有名词用英文。`{tool:narrate}` 不推进游戏，也不计入章节计时；`{tool:act}` 的 `thought` 照常写。系统内置解说计时：思考状态（不算工具运行与游戏推进）累计满 {remind} 还没有更新时，会在你下一次调用工具时提醒你。
- **调用工具期间实时更新工具状态**：运行耗时较长的程序时，在程序里定期调用 `/workspace/game/show.py` 的 `status("……")` 报告进度（一句中文，可以写进度数字，例如"第 3 轮，已试 2 万条"），HUD 的工具栏会实时显示；这次工具调用返回后自动清掉。用法：`import sys; sys.path.insert(0, "/workspace/game"); from show import status`。
