# 剧情与任务边界

当前为 agent 剧情模式。移动、暂停、菜单、重试、对白选择、结算和换章均由你显式决定；主控核验状态，不隐式代按或传送。先读 story 中的当前内容与选项，再选择行动。

教学提示可见时，按观测的 `controllable` 判断角色是否已可操作。`act` 的 `stop_on` 若含 `controllable` 且角色起初就可操作，会立即返回 0 帧。角色可操作时直接发教学按键，省略这个截断条件。

complete 事件或 completed=true 只表示游戏登记了成绩。自行处理确认与结算，按主控反馈核验整章完成。主控提示仍需返回选章地图时，显式操作菜单；还有计划目标时按新目标自行导航。
中途检查点目标抵达即可完成，无需为此退出关卡。计划结束是否继续活动，遵循本次停止条件；以主控的任务完成／结束报告为准。
