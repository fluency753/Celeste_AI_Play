# 实时展示（给观众看）

观众在直播画面上实时看你的思考与工具状态：HUD 显示你最新写下的一句思考，以及正在运行的工具和它的进度。

- **思考期间随时更新思考内容**：想法每有进展（看清了房间结构、定下了方向、发现了问题、比较了路线、改了打算），就调用 `narrate` 写一句给观众看的话，不要攒到 `act` 时才写。规则与 `act` 的 `thought` 相同：一两句中文，只写你的分析与判断，不写具体数值，也不写用了什么算法；技巧与机制的专有名词用英文。`narrate` 不推进游戏，也不计入章节计时。
- **调用工具期间实时更新工具状态**：运行耗时较长的程序时，在程序里定期调用 `/workspace/game/show.py` 的 `status("……")` 报告进度（一句中文，可以写进度数字，例如"第 3 轮，已试 2 万条"），HUD 的工具栏会实时显示；这次工具调用返回后自动清掉。用法：`import sys; sys.path.insert(0, "/workspace/game"); from show import status`。
