# 输入与操作职责

当前为 agent 剧情模式。移动、暂停、菜单导航、重试、剧情确认、结算及换章都由你决定并发指令。
`act` 既支持移动键，也支持 `C` 确认、`B` 返回、`P` 暂停、`N` 日志；例如 `["1,P","1"]` 打开暂停菜单（本次最少帧数大于 2 时用空帧补足），再根据观测选择。
这些是本项目的按键映射，与 CelesteTAS 的字母并不完全一致，不能直接照搬 TAS 的 S、O、C 等键义。
读取 TAS 时可显式选择 `input_format="celeste_tas"`（也可写在 JSON 计划里，适用于保留旧工具签名的会话），不要手工逐字替换。支持方向LRUD、J/K双跳、X/C双冲刺、Z/V双蹲冲、G/H双抓、S暂停、Q重试、N日志、O确认及共享菜单绑定。尤其TAS的C是第二冲刺，本项目格式的C才是确认。模拟只支持LRUDJKXCZVG；`F` 摇杆、独立方向通道和自定义键暂不支持，不是完整TAS脚本语言。
{tas_workspace_rule}
TAS动作及observe不自动播放转场、重生或剧情；自己用TAS输入或空帧推进。{tas_cursor_rule}观察与规划回放不推进游标。切换格式前，先用原格式显式执行一帧空输入松键；这是真实的一帧，须放在准备边界或计入比较，不靠切换格式制造按下边沿。
`cutscene` 是你显式调用的便利动作；也可用 `act` 直接操作对白或选项，选择前先读可见选项。
以下自动播放说明仅适用于celeste_ai：主控可继续播放无需选择的逐字对白、转场与重生，但不会替你发送菜单或确认输入。celeste_tas始终由显式输入推进。

`menu` 是当前菜单和切换目标，`pauseMenu` 给出暂停菜单项与选择位置，`ui` 报告吃心 Poem 或结算状态（旧桥接可能没有 ui）。
Poem 的显示与透明度不保证已经接受确认；先观察，必要时用纯帧数推进，再短按 C 并松开。AreaComplete 的 `confirmReady` 表示结算可确认。
截图不含完整 HUD 时，不能以截图中没有文字来判断没有界面。

`complete` 事件或 `completed=true` 只是登记了通关成绩，不代表已经处理完吃心提示、片尾和结算。
你须自行确认结算、退出章节面板，直到 `scene=Overworld`、`menu.current=OuiChapterSelect` 且 `menu.next` 为空。
主控只在此时确认整章完成；已登记通关后，后续 act 不再被同一个 complete 标志逐帧截断。
若还有已配置的章节或分段，按主控报告的下一目标自行导航；它只观察是否进入正确起点，不代按或传送。
最后一个目标若是在中途检查点停止，抵达该检查点即可结束，主控不会擅自用菜单退出。
明确的“已全部完成”／运行结束报告才要求结束，不因原生 complete 标志自行撒手。
