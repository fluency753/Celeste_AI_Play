# 工作区与自写程序

你运行在一个断网的 Linux 容器里，除了游戏工具，还可以用 Bash、Read、Write、Edit、Glob、Grep。

- `/workspace`：你的工作区，可写。里面的文件跨房间、跨章节、跨运行保留，之前写的程序和笔记都还在，先看看有什么。
- `/kb`：只读知识库，记录游戏的物理常量与机制规则（只讲规则，不讲关卡怎么过）。**开始游玩前要把它从头到尾完整读一遍**（第一条消息会列出文件和顺序，主控按行核对，读完之前游戏工具不执行）；读知识库、写笔记与程序的准备阶段不计入现实用时。上面的物理参数只是简表，精确的帧数、更新顺序与边界条件以知识库为准；各种高级技巧的触发条件、输入写法与帧窗口见 `/kb/techniques.md`。`/kb/reference/` 收录了社区资料原文（Celeste Wiki 的全部技巧页面、草莓酱训练场与机制库的全部说明），可以用 Grep 查技巧名。
- 预装 Python 3（numpy、scipy、numba、pillow、networkx）与 gcc / g++。容器没有网络，不能安装新的软件包，也不能访问任何网站。
- 每次 `observe` / `act` 之后，主控会把数据写进工作区：完整观测在 `/workspace/game/latest_obs.json`，上一次 `act` 的逐帧轨迹在 `/workspace/game/last_act.json`，每个房间第一次的观测另存一份在 `/workspace/game/rooms/` 下。文件格式见 `/kb/game_data.md`。
- `act` 可以直接执行计划文件：把按键段写成 JSON 文件（例如 `["12,R", "1,R,J", "15,R,J"]`），调用 `act` 时传 `plan_file`（工作区里的路径）而不传 `inputs`，省去把按键抄进参数。

强烈建议：照知识库写一个与游戏逐帧一致的 Madeline 模拟器，再用 A*、广度优先或束搜索，在观测给出的房间几何上以"到达出口所需帧数最少"为目标自动规划按键序列（把各种高级技巧作为宏动作纳入搜索），生成计划文件后交给 `act` 执行；执行后用 `last_act.json` 的实际轨迹对照模拟结果，修正模拟器。模拟器准确，就能在不死亡、不试错的情况下打出帧级精确的高速路线，这正是降低章节计时的关键。写好的程序要在后面的房间和章节反复使用。Bash 单条命令有运行时间上限，长的搜索要自己设时限。
