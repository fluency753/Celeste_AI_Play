让大模型智能体（Opus 5.5、Fable 5.1 等，也可以通过兼容接口接入其他平台的模型，如 DeepSeek）在断网沙箱中独立游玩《蔚蓝》（Celeste）官方章节：游戏可逐帧暂停，智能体想好下一段操作后再推进；OBS 只录下真正推进的游玩帧，跳过所有思考时间。

本轮目标：**从正式存档进入序章起，通关序章、1A 与 2A，游戏内章节计时尽可能短，多用高级技巧，打出精彩的操作。** 现实时间是次要指标，只设一个宽松的上限（最初的设想是 2 小时内通关 1A 与 2A，现已放宽）。调试与工具准备在单独的 `test` 存档上进行，不计时。

## 工作原理

![总体架构](docs/images/architecture.png)

- **桥接 Mod**（Everest Mod，运行在游戏进程内）：逐帧暂停与放行游戏、注入按键、提取 Madeline 状态与碰撞箱、截图，并报告暂停菜单状态，让主控像玩家一样通过暂停菜单跳过剧情。
- **主控**：唯一同时连接游戏、智能体、HUD 与 OBS 的组件，负责决策循环、执行与日志；智能体用 `set_effort` 申请调整推理强度时，在两轮之间替它切换；执行智能体程序算出的计划，偏离预期时停下（`--free-planning` 时还可在零网络沙箱里运行智能体的重算程序自动重试）；按"每次暂停一轮工具"的规则放行或拒绝容器里的工具调用；一章通关后自动进入下一章；Max 额度用完时让游戏冻结、等额度重置后接着玩。
- **预置模拟器**（可选，`--sim`）：由完整游戏代码逐帧推演的无画面模拟器，从游戏导出的某一帧完整场景出发，给出任意按键之后每一帧的结果，与真实游戏逐帧一致；只读挂进容器供智能体调用。它含反编译代码，只在本机构建，不在仓库里。
- **智能体容器**：智能体就是运行在 Docker 容器里的官方 Claude Code，默认用 Max 套餐登录，无需 API 密钥；也可以用 `--provider` 接入其他平台兼容 Anthropic 接口的模型（如 DeepSeek），工具、提示词、知识库与沙箱完全相同，API 密钥只从本机读取、不入库。容器出站只放行所用模型平台的域名与主控端口，联网工具全部禁用，自写程序在无网络的 Bash 沙箱里运行，看不到游戏代码与进程。
- **HUD**：右上角置顶半透明卡片，显示游戏时间、推理强度、思考与工具时间、上下文大小、压缩次数、当前房间与当前思考。
- **OBS 锁步插件**：录制时 OBS 每个视频节拍向游戏要一帧，游戏推进一帧、画完再回复；插件自带的录制输出只把这些帧交给 ffmpeg，思考期间一帧也不写，成片帧数与游玩帧数一一对应。游戏停住时声音一起冻结，插件用每段开头"静音→有声"的那条边逐段校准音画同步。

智能体容器的隔离已逐项验收（`python -m orchestrator.verify`）：容器里的 Claude Code 只能连到 Anthropic 官方域名与主控的游戏工具端口，连不上任何网站，也连不上游戏桥接端口；它用 Bash 运行的自写程序处在零网络的沙箱里，连 Anthropic 也连不上，也看不到登录令牌；它改不了防火墙与托管配置，也不读取任何可被它改写的设置文件。工作区 `workspaces/<标签>/` 跨运行保留，主控每次观测都把房间数据写进去；知识库 `kb/` 只读挂载，只讲游戏规则，不讲关卡怎么过。

为了在合理的现实时间内打出短的游戏内计时，智能体按三层控制工作：大模型规划路线，具体按键由程序搜索生成（可以用自己写的模拟器，也可以用 `--sim` 开放的预置模拟器），执行器以 60 fps 全速执行。默认每次暂停（`act` 返回、游戏冻结）只允许智能体思考一轮、调用一轮工具，然后必须执行：路线没把握也要上去试，试错过程真实发生在游戏里、录进录像，每次尝试都换一句新的思考语句；`--free-planning` 取消这个限制，恢复计划文件的自动重试。

## 目录结构（规划中）

```text
Celeste_AI_Play/
├── game-bridge/     桥接 Mod（C#，Everest）
├── obs-plugin/      OBS 锁步插件（C/C++，libobs）
├── orchestrator/    主控与执行器（Python）
├── agent-container/ 智能体容器（Claude Code、防火墙、托管配置）
├── kb/              知识库（物理常量、机制规则、工作区数据格式；只读挂载进容器）
├── overlay/         HUD 页面与置顶窗口
├── configs/         配置
├── calibration/     校准与验收测试
├── docs/            文档
├── tools/           测试客户端与安装脚本
├── sim/             预置模拟器（含反编译代码，只在本机，不入库）
└── runs/            运行产出（不入库）
```

目前已有 `docs/`、`game-bridge/`（桥接 Mod）、`obs-plugin/`（OBS 锁步录制插件）、`orchestrator/`（主控、游戏工具服务、容器管理、录制与验收）、`agent-container/`（智能体镜像、防火墙与托管配置）、`kb/`（知识库）、`overlay/`（HUD 页面、服务与置顶窗口）、`configs/`（HUD 与录制配置）、`calibration/`（验收与校准脚本）与 `tools/`（测试客户端、菜单宏、OBS 配置与安装脚本）。

## 游戏文件与版权

本仓库不包含《蔚蓝》的游戏文件、资源或反编译代码，运行需要自行购买正版游戏。知识库只收录事实性的物理参数与机制描述。
