让大模型智能体（Opus 5.5、Fable 5.1 等）在断网沙箱中独立游玩《蔚蓝》（Celeste）官方章节：游戏可逐帧暂停，智能体想好下一段操作后再推进；OBS 只录下真正推进的游玩帧，跳过所有思考时间。

本轮目标：**从正式存档进入序章起，智能体在 2 小时现实时间内至少通关 1A 与 2A。** 调试与工具准备在单独的 `test` 存档上进行，不计时。

## 工作原理

![总体架构](docs/images/architecture.png)

- **桥接 Mod**（Everest Mod，运行在游戏进程内）：逐帧暂停与放行游戏、注入按键、提取 Madeline 状态与碰撞箱、截图、自动跳过剧情。
- **主控**：唯一同时连接游戏、智能体、HUD 与 OBS 的组件，负责决策循环、执行与日志。
- **智能体容器**：智能体就是运行在 Docker 容器里的官方 Claude Code，用 Max 套餐登录，无需 API 密钥。容器出站只放行 Anthropic 官方域名与主控端口，联网工具全部禁用，自写程序在无网络的 Bash 沙箱里运行，看不到游戏代码与进程。
- **HUD**：右上角置顶半透明卡片，显示游戏时间、思考与工具时间、上下文大小、压缩次数、当前房间与当前思考。
- **OBS 锁步插件**：OBS 每个视频节拍放行一个游戏帧，思考期间录制暂停，录像帧数与游玩帧数一一对应。

为了在 2 小时内通关，智能体按三层控制工作：大模型每个房间只规划一两次，具体按键由它自己写的模拟器与搜索程序生成，执行器以 60 fps 全速执行。

![三层控制](docs/images/three-tier-control.png)

## 目录结构（规划中）

```text
Celeste_AI_Play/
├── game-bridge/     桥接 Mod（C#，Everest）
├── obs-plugin/      OBS 锁步插件（C/C++，libobs）
├── orchestrator/    主控与执行器（Python）
├── agent-container/ 智能体容器（Claude Code、防火墙、托管配置）
├── kb-builder/      知识库生成（离线）
├── overlay/         HUD 页面与置顶窗口
├── configs/         配置
├── calibration/     校准与验收测试
├── docs/            文档
├── tools/           测试客户端与安装脚本
└── runs/            运行产出（不入库）
```

目前已有 `docs/`、`game-bridge/`（桥接 Mod）与 `tools/`（测试客户端与安装脚本），其余目录会随里程碑推进逐步加入。

## 游戏文件与版权

本仓库不包含《蔚蓝》的游戏文件、资源或反编译代码，运行需要自行购买正版游戏。知识库只收录事实性的物理参数与机制描述。
