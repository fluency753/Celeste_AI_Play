## 工作原理

![总体架构](docs/images/architecture.png)

- **桥接 Mod**（Everest Mod，运行在游戏进程内）：逐帧暂停与放行游戏、注入按键、提取 Madeline 状态与碰撞箱、截图，并报告暂停菜单状态，让主控像玩家一样通过暂停菜单跳过剧情。
- **主控**：唯一同时连接游戏、智能体、HUD 与 OBS 的组件，负责决策循环、执行与日志；智能体用 `set_effort` 申请调整推理强度时，在两轮之间替它切换；执行智能体程序算出的计划，偏离预期时停下（默认还可在零网络沙箱里运行智能体的重算程序自动重试）；`--limit-planning` 时按章节的规划轮次放行或拒绝容器里的工具调用；执行之前把这次规划在模拟器里推演过的路线画进游戏（规划回放）；一章通关后自动进入下一章；Max 额度用完时让游戏冻结、等额度重置后接着玩。
- **预置模拟器**（默认开启，`--no-sim` 关闭）：由完整游戏代码逐帧推演的无画面模拟器，从游戏导出的某一帧完整场景出发，给出任意按键之后每一帧的结果，与真实游戏逐帧一致；推演到中途的任何一帧都能存成检查点、从检查点接着推演。只读挂进容器供智能体调用。它含反编译代码，只在本机构建，不在仓库里（见下文"不在仓库里的本机文件"）。这个开关把项目分成两个版本，提示词各一套，目标都是以最短的章节计时通关：开模拟器时智能体可以随意调用模拟器寻找并优化路线；关模拟器时智能体不能调用模拟器，提示词不教打法，只靠它自己的办法——它不管用什么方法算出 Madeline 的逐帧轨迹，都可以交给展示接口，系统同样画给观众看（只用于展示，不影响成绩）。目前用开模拟器的版本。
- **智能体容器**：智能体就是运行在 Docker 容器里的官方 Claude Code，默认用 Max 套餐登录，无需 API 密钥；也可以用 `--provider` 接入其他平台兼容 Anthropic 接口的模型（如 DeepSeek；GPT 经本机的接口转换网关接入，目前只有接口、尚未实测），工具、提示词、知识库与沙箱完全相同，API 密钥只从本机读取、不入库。容器出站只放行所用模型平台的域名与主控端口，联网工具全部禁用，自写程序在无网络的 Bash 沙箱里运行，看不到游戏代码与进程。
- **HUD**：右上角置顶半透明卡片，显示游戏时间、推理强度、思考与工具时间、上下文大小、压缩次数、知识库读取用时、死亡次数、模拟器调用次数、当前这次调用推演的路径条数、当前房间推演出的最速用时、正在调用的工具（放不下时折行）、当前房间与当前思考；规划回放时显示第几轮、推演了多少条路线。实时展示（默认开启，`--no-live` 关闭）时，智能体思考期间用 `narrate` 随时更新 HUD 上的思考语句，运行程序期间实时报告进度；系统内置半分钟计时器，思考累计满 30 秒没有更新就在它下一次调用工具时提醒。
- **OBS 锁步插件**：录制时 OBS 每个视频节拍向游戏要一帧，游戏推进一帧、画完再回复；插件自带的录制输出只把这些帧交给 ffmpeg，思考期间一帧也不写，成片帧数与游玩帧数一一对应。游戏停住时声音一起冻结，插件用每段开头"静音→有声"的那条边逐段校准音画同步。每次录制出两个版本：含规划回放的完整版 `gameplay.mkv`，和只有真实游玩帧的纯享版 `gameplay_pure.mkv`。录屏开关默认开启（`--no-record` 关闭）：OBS 没在运行时主控自己启动它、结束时关掉。

智能体容器的隔离已逐项验收（`python -m orchestrator.verify`）：容器里的 Claude Code 只能连到所用模型平台（默认 Anthropic 官方域名）与主控的游戏工具端口，连不上任何网站，也连不上游戏桥接端口；它用 Bash 运行的自写程序处在零网络的沙箱里，连 Anthropic 也连不上，也看不到登录令牌；它改不了防火墙与托管配置，也不读取任何可被它改写的设置文件。工作区 `workspaces/<标签>/` 跨运行保留，主控每次观测都把房间数据写进去；知识库 `kb/` 只读挂载，只讲游戏规则，不讲关卡怎么过。

为了在合理的现实时间内打出短的游戏内计时，智能体按三层控制工作：大模型规划路线，具体按键由程序搜索生成（开模拟器的版本用预置模拟器，关模拟器的版本用它自己的办法），执行器以 60 fps 全速执行。默认不限制思考与模拟器调用，观测里也不显示现实用时与预算：智能体把整个房间在模拟器里推演到出口、找到能过的路线之后继续优化、多用高阶技巧与机制，优化完再一次执行，没推演到出口的路线不执行，需要分段搜索时用检查点，搜索怎么写由它自己决定（`--limit-planning` 打开按章节记账的规划轮次：一屏大小的房间 3 轮，长、高每加倍轮次翻倍，至少 3 轮，死一次补 1 轮，只有调用模拟器的消息占一轮）。每规划完一轮（一条调用了模拟器的消息），主控就把这一轮在预置模拟器里推演过的路线按推演先后画进游戏（规划回放）：每 100 条推演画一条、每轮至少 40 条，3 倍速，线条延伸时是绿色，死亡的线从死亡点往回变红，这一轮最快的一条变成金色，镜头跟着金色路线走（变金时跟着变色点往回移），放完变灰留在画面上，开始真实执行时全部清掉；回放不推进游戏、不计章节计时，照常录进录像，音乐照常播放、保持原速。

## 快速开始

在一台装好 Steam 版《蔚蓝》的 Windows 电脑上：

```powershell
git clone https://github.com/fluency753/Celeste_AI_Play.git
cd Celeste_AI_Play
powershell -ExecutionPolicy Bypass -File .\setup.ps1          # 一键部署：逐步检查与安装，配置平台、存档与开关，生成启动脚本
.\start_local.ps1 -Trial                                      # 在调试存档上试跑
.\start_local.ps1                                             # 正式挑战
```

也可以直接运行主控：

```powershell
# 正式挑战：预置模拟器、实时展示、规划回放、OBS 录屏都默认开启
.\.venv\Scripts\python.exe -m orchestrator.run --agent opus5.5 --save opus5.5 --model opus --chapters 0,1,2 --max-minutes 600
# DeepSeek，在调试存档上试跑、不录屏
.\.venv\Scripts\python.exe -m orchestrator.run --agent dev-deepseek --save test --provider deepseek --model deepseek-flash --chapter 0 --no-record
```

环境要求、手动部署步骤与每个命令的细节见 [docs/DEPLOY.md](docs/DEPLOY.md)。

## 开关

主控 `python -m orchestrator.run` 的全部开关与参数。续跑（`--resume`）时，标了"沿用"的项不写就沿用原运行的设置。

**版本与功能开关**

| 开关 | 默认 | 作用 |
| --- | --- | --- |
| `--sim` / `--no-sim` | 开（沿用） | 预置模拟器，把项目分成两个版本。开：模拟器只读挂进容器，智能体可以随意调用它寻找并优化路线，提示词写明做法；关：不能调用模拟器，提示词不教打法，只写目标、规则与工具接口，智能体自己想办法（算出的轨迹可以交给展示接口画出来） |
| `--live` / `--no-live` | 开（沿用） | 实时展示。开：智能体思考期间用 `narrate` 随时更新 HUD 的思考，运行程序时用 `show.status()` 报告进度，思考满 30 秒没更新时提醒它；关：HUD 的思考只在每次 `act` 时更新 |
| `--record` / `--no-record` | 开（沿用） | OBS 录屏。开：OBS 没在运行就由主控启动，锁步录制完整版与纯享版，结束时关掉它启动的 OBS（已经开着的 OBS 直接用、不关）；关：不启动、不调用 OBS |
| `--playback` / `--no-playback` | 开（沿用） | 规划回放。开：每规划完一轮，把推演过的路线按轮画进游戏给观众看（开模拟器时画 `/sim` 的推演，关模拟器时画智能体交来的轨迹），不推进游戏、不计章节计时；关：不画 |
| `--limit-planning` | 关 | 限制规划轮次：按章节记账，每个新房间按大小存入轮次，死亡补 1 轮，只有调用模拟器的消息占一轮，自动重试随之关闭；只用于开模拟器的版本 |
| `--no-study` | 关 | 跳过准备阶段（开局读完知识库），调试用 |
| `--no-quota-wait` | 关 | Max 额度用完时直接停止，而不是冻结游戏、等额度重置后接着玩 |
| `--no-hud-window` | 关 | 不在屏幕上打开置顶 HUD 窗口（录像里的 HUD 不受影响） |
| `--no-hud` | 关 | 连 HUD 服务也不启动 |
| `--record-marker` | 关 | 录制时在画面左下角画帧号条码，只用于校准 |
| `--skip-enter` | 关 | 已在关卡内可操作时跳过菜单宏 |
| `--no-agent` | 关 | 只启动游戏工具服务、不启动智能体，手动调试用 |
| `--fresh-session` | 关 | 与 `--resume` 一起用：开一个新的 Claude Code 会话，不接原来的 |

**运行参数**

| 参数 | 默认 | 作用 |
| --- | --- | --- |
| `--agent <标签>` | 必填 | 智能体标签：决定容器 `celeste-agent-<标签>`、工作区 `workspaces\<标签>\`、日志 `runs\<标签>\` |
| `--save <存档名>` | 必填 | 游戏内存档名，与当前存档不一致时拒绝开始 |
| `--provider` | `anthropic`（沿用） | 模型平台：`anthropic`（Max 订阅令牌）、`deepseek`、`openai`（GPT，只有接口、尚未实测）或自定义平台 |
| `--model` | `opus`（沿用） | Anthropic 用别名（`opus`、`fable`、`haiku`）；第三方用它自己的模型名 |
| `--effort` | `high`（沿用当时生效的） | 开局推理强度 `low` / `medium` / `high` / `xhigh` / `max`；智能体可以用 `set_effort` 自己调整 |
| `--chapters 0,1,2` | 无 | 依次通关的章节（0 序章、1 1A、2 2A），一章通关后自动进入下一章 |
| `--chapter N` | 选章页当前章节 | 只玩一章 |
| `--max-minutes` | 240（沿用） | 现实时间安全上限（不含准备阶段与等待额度），不显示给智能体 |
| `--study-minutes` | 60 | 准备阶段上限，到时自动开放游戏工具 |
| `--resume <运行目录>` | 无 | 续跑一次中断的运行（游戏须仍冻结在原处） |
| `--max-usage 0~1` | 不设 | Max 订阅：用量到这个比例就提前暂停、等重置 |
| `--quota-wait-max-hours` | 24 | 额度重置还要等超过这么多小时就停止本次运行 |
| `--rounds-per-room` / `--room-scale` | 3 / 2 | `--limit-planning` 时：一屏大小的房间存入几轮 / 房间长、高每变成几倍轮次乘几 |
| `--autocompact` | 平台默认 | 上下文自动压缩的窗口：`auto` 或 100000～1000000 token |
| `--runtime` | `container`（沿用） | `host`：在本机运行、只开放游戏工具（早期的过渡方式，没有沙箱与模拟器） |
| `--ffmpeg` / `--record-video-args` / `--audio-offset-ms` | 见录制配置 | 临时覆盖 ffmpeg 路径、视频编码参数、声音偏移 |
| `--bridge-port` / `--mcp-port` / `--hud-port` | 47774 / 47780 / 47790 | 桥接、游戏工具服务、HUD 的端口 |
| `--play-speed` / `--auto-speed` | 1 / 1 | 动作段 / 转场与剧情段的推进速度，大于 1 是快进，只用于调试（录像会失真） |

| --- | --- | --- |
| `sim\dist\` | 预置模拟器：`celeste-sim`（Linux 单文件程序，在容器里运行）、`sim.py`（Python 接口）、`README.md`、`sim_assets.json`、`statemap.json`、`VERSION`。由游戏代码生成，不公开分发 | 从开发机把整个文件夹复制到新仓库的同一位置（主控固定从这里挂进容器的 `/sim`）；没有时用 `--no-sim` 运行关模拟器的版本 |
| `kb\reference\` | 知识库参考资料原文：Celeste Wiki 技巧页面、草莓酱训练场与机制库（中英文）、社区资料（文字版与 PDF） | 复制整个文件夹，或用 `tools\fetch_reference.py`、`tools\import_reference_pdf.py` 重新生成；没有时只读知识库正文 |

| `configs\local.*.json` | 本机路径、密钥文件位置、录制参数 | 由部署向导重新写 |
| `workspaces\`、`runs\` | 智能体写的程序与笔记；运行记录、录像、存档备份 | 想延续进度时复制 |

## 目录结构

```text
Celeste_AI_Play/
├── setup.ps1        一键部署入口（Python 与虚拟环境，然后启动部署向导）
├── game-bridge/     桥接 Mod（C#，Everest）
├── obs-plugin/      OBS 锁步插件（C，libobs）
├── orchestrator/    主控：游戏工具服务、决策循环、执行与自动重试、规划回放、录制、容器管理、提示词
├── agent-container/ 智能体镜像（Claude Code、出站防火墙、托管配置、工具门控钩子）
├── kb/              知识库（物理常量、机制规则、技巧、工作区数据格式；只读挂进容器）
├── overlay/         HUD 页面、服务与置顶窗口
├── configs/         HUD、录制与模型平台配置
├── calibration/     校准与验收测试
├── docs/            文档（部署、使用、设计）
├── tools/           部署向导、测试客户端、菜单宏、OBS 配置、插件构建与资料抓取脚本
├── sim/             预置模拟器（只在本机，不入库）
├── workspaces/      智能体工作区（不入库）
└── runs/            运行产出（不入库）
```

## 游戏文件与版权

本仓库不包含《蔚蓝》的游戏文件、资源或反编译代码，运行需要自行购买正版游戏。知识库只收录事实性的物理参数与机制描述。
